# Редактор портов

**Редактор портов (Port Editor)** позволяет настраивать назначение контактов ЭБУ и соответствие цифровых выходов. В этом документе описаны интерфейс редактора, типовые конфигурации и устранение неполадок.

## Обзор

Редактор портов позволяет:
- **Назначать функции контактам:** привязывать форсунки, зажигание и дополнительные выходы к контактам ЭБУ.
- **Группировать назначения по категориям:** форсунки, зажигание, дополнительные выходы и входы отображаются отдельно.
- **Просматривать схему контактов:** видеть расположение аппаратных контактов с группировкой по уровням напряжения и типам.
- **Проверять назначения:** получать автоматические предупреждения о неназначенных обязательных функциях.
- **Обнаруживать конфликты:** получать предупреждения, если несколько функций назначены на один контакт.

## Открытие редактора портов

Редактор открывается через меню **Setup → Programmable Ports** (Настройка → Программируемые порты).

**Примечание:** точный путь зависит от определения INI вашего ЭБУ. В большинстве случаев пункт находится в меню Setup, но у некоторых ЭБУ он может располагаться в Tools или Hardware. Встроенная функция `std_port_edit` будет работать, если в разделе `[Menu]` INI-файла присутствует запись `subMenu = std_port_edit, "Label"`.

## Интерфейс пользователя

### Левая панель: назначение функций

Здесь доступны функции, сгруппированные по типам:
- **Форсунки:** INJ1–INJ8 и далее (обязательна как минимум INJ1).
- **Зажигание:** IGN1–IGN8 и далее (обязательна как минимум IGN1).
- **Дополнительные выходы:** AUX1–AUX16 (бензонасос, вентилятор и т. п.).
- **Входы:** TPS (положение дросселя), MAP (давление во впуске/наддув), CLT (температура охлаждающей жидкости), IAT (температура воздуха на впуске), O2 (кислородный датчик), напряжение аккумулятора, VR-датчики (коленвал/распредвал).

Для каждой функции отображаются:
- **Значок:** цветная точка, обозначающая тип функции.
- **Название:** подпись функции (например, «Форсунка 1»).
- **Метка Required:** красная метка для функций, назначение которых обязательно.
- **Раскрывающийся список:** выбор физического контакта для этой функции.

### Правая панель: схема аппаратных контактов

Графическое представление доступных контактов:
- **Выходы верхнего плеча:** HSO1–HSO8 (драйверы форсунок 12 В).
- **Выходы нижнего плеча:** LSO1–LSO8 (драйверы зажигания 5 В).
- **Аналоговые входы:** ADC0–ADC7 (входы датчиков).
- **Цифровые и VR-входы:** DIN1–DIN8, VR1±, VR2± (датчики коленвала/распредвала).
- **Шина CAN:** CANH, CANL (если поддерживается).

Цвета контактов обозначают:
- **Сплошная рамка:** контакт уже назначен функции.
- **Пунктирная рамка:** контакт доступен для назначения.
- **Цвет:** соответствует типу функции (зелёный — форсунки, оранжевый — зажигание и т. д.).

### Поиск и предупреждения

**Фильтр поиска:** введите текст, чтобы быстро найти функцию (например, `fuel` найдёт бензонасос).

**Панель предупреждений** (если отображается):
- показывает красным неназначенные обязательные функции;
- отображает количество конфликтов (если они есть);
- показывает не более трёх предупреждений; нажмите на панель, чтобы развернуть список.

### Правила обнаружения конфликтов

Проверка конфликтов контактов перед записью конфигурации (burn) выполняется по следующим правилам:

- **Отключённая функция не занимает контакт.** Во многих полях контактов INI задаётся условие применимости (например, контакт датчика детонации нужен только при включённом обнаружении детонации). Если условие ложно, контакт считается неназначенным: он не вызывает конфликт и не мешает использовать этот контакт для другой функции. Если условие невозможно разобрать, контакт остаётся в проверке: пропустить реальный конфликт хуже, чем показать лишнее предупреждение.
- **Board Default не считается контактом.** Варианты, оставленные в положении значения платы по умолчанию, не участвуют в проверке конфликтов.
- **Проверка контактов не блокирует загрузку калибровки.** Конфликты вызывают предупреждения перед записью конфигурации в ЭБУ, но не мешают открыть чужую калибровку.

## Типовые конфигурации

### 4-цилиндровый двигатель (Speeduino)

```
Injectors:
  INJ1 → HSO1
  INJ2 → HSO2
  INJ3 → HSO3
  INJ4 → HSO4

Ignition:
  IGN1 → LSO1
  IGN2 → LSO2
  IGN3 → LSO3
  IGN4 → LSO4

Inputs:
  TPS → ADC0
  MAP → ADC1
  CLT → ADC2
  IAT → ADC3
  O2 → ADC4
  Battery → ADC5
  Crank → VR1+/VR1-
  Cam → VR2+/VR2- (optional)

Auxiliary:
  Fuel Pump → LSO7
  Fan → LSO8
```

### 6-цилиндровый двигатель (rusEFI)

Схема аналогична 4-цилиндровому двигателю, но:
- используются назначения INJ1–INJ6 и IGN1–IGN6;
- структура входов остаётся такой же;
- названия контактов могут отличаться в зависимости от платы.

### Двигатель с турбонаддувом

Базовая схема такая же, как у атмосферного двигателя, но могут добавляться:
- **Управление наддувом:** AUX1 для соленоида вестгейта.
- **Anti-Lag:** AUX2 для соленоида отсечки топлива.
- Структура форсунок и зажигания остаётся прежней.

## Рекомендации

1. **Назначьте все обязательные функции** перед сохранением.
   - Обязательные функции отмечены красной меткой Required.
   - Если какая-либо функция не назначена, система выдаст предупреждение.

2. **Используйте выходы верхнего плеча для форсунок.**
   - HSO (12 В) предназначены для управления форсунками.
   - Они обеспечивают необходимый ток для топливных форсунок.

3. **Используйте выходы нижнего плеча для катушек.**
   - LSO (5 В) управляют первичными цепями катушек зажигания.
   - Это соответствует типичным требованиям драйверов катушек.

4. **Разделяйте аналоговые входы по каналам ADC.**
   - Для каждого аналогового входа используйте отдельный канал ADC.
   - Общие каналы могут вызывать взаимные помехи.

5. **Сверяйте назначения со схемой ЭБУ.**
   - У разных плат различается физическое расположение контактов.
   - Всегда пользуйтесь документацией именно на вашу плату.

6. **Проверяйте мультиметром (требуется перезапуск питания).**
   - После сохранения конфигурации перезапустите питание ЭБУ.
   - Проверьте правильность напряжения и наличия массы на каждом выходе.
   - Убедитесь, что входы показывают корректные значения датчиков.

## Устранение неполадок

### Ошибка «Function X is already assigned»

**Причина:** две функции пытаются использовать один и тот же контакт.

**Решение:**
1. Назначьте одной из функций другой контакт.
2. Проверьте свободные контакты на графической схеме.
3. Устраните все конфликты перед сохранением.

### Предупреждение «Required function X is not assigned»

**Причина:** обязательная функция оставлена без назначения.

**Решение:**
1. Нажмите на предупреждение, чтобы увидеть список неназначенных функций.
2. Назначьте каждой обязательной функции свободный контакт.
3. Сохранение будет заблокировано, пока все обязательные функции не будут назначены.

### Редактор портов не открывается

**Причина:**
- пункт меню «Programmable Ports» отсутствует в разделе `[Menu]` вашего INI;
- версия INI не содержит поддержки редактора портов.

**Решение:**
- проверьте наличие записи `subMenu = std_port_edit, "Programmable Ports"` в разделе `[Menu]`;
- если записи нет, может потребоваться обновить прошивку ЭБУ или описание INI;
- не все ЭБУ поддерживают настройку портов;
- проверьте документацию ЭБУ на предмет поддерживаемых функций.

### Изменения не сохраняются

**Причина:** не была нажата кнопка **Save Configuration**.

**Решение:**
- всегда нажимайте **Save Configuration**, чтобы сохранить изменения;
- индикатор несохранённых изменений отображает красную надпись «Unsaved changes»;
- при закрытии окна без сохранения назначения будут потеряны.

## Примечания для отдельных ЭБУ

### Speeduino

- На большинстве плат используется распиновка, совместимая с MegaSquirt.
- Внимательно сверяйте расположение контактов конкретной платы (v0.3, v0.4, v3.57 и т. д.).
- Часто используется STM32F407 со стандартной схемой расположения контактов.

### rusEFI (платы STM32)

- Названия контактов различаются в зависимости от платы (Proteus F4, Frankenso и т. д.).
- Всегда сверяйтесь со схемой контактов конкретной платы.
- На некоторых платах количество контактов ограничено — проверьте свою модификацию.

### epicEFI

- Распиновка похожа на rusEFI.
- Проверьте вариант платы (256C и т. д.).
- В некоторых конфигурациях может поддерживаться двухбаночный впрыск топлива.

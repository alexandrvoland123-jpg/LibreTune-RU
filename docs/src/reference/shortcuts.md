# Общие сочетания клавиш

Полный справочник сочетаний клавиш LibreTune.

## Операции с файлами

| Сочетание | Действие |
|---|---|
| Ctrl+N | Создать проект |
| Ctrl+O | Открыть проект / загрузить калибровку |
| Ctrl+S | Сохранить калибровку |
| Ctrl+Shift+S | Сохранить калибровку как |
| Ctrl+B | Записать калибровку в ЭБУ |
| Ctrl+Q | Закрыть приложение |

## Навигация по меню

В верхней строке меню поддерживается навигация в стиле Windows с помощью **Alt + клавиша доступа**. В каждом меню одна буква подчёркнута; нажмите `Alt` и эту букву, чтобы открыть меню, затем используйте стрелки и `Enter` для выбора.

| Сочетание | Действие |
|---|---|
| Alt+F | Открыть меню «Файл» |
| Alt+E | Открыть меню «Правка» |
| Alt+V | Открыть меню «Вид» |
| Alt+T | Открыть меню «Инструменты» |
| Alt+(буква) | Открыть меню ЭБУ по подчёркнутой букве |
| ← / → | Перемещение между меню верхнего уровня |
| ↑ / ↓ | Перемещение внутри открытого меню |
| Enter | Активировать выделенный пункт меню |
| Esc | Закрыть открытое меню |

> Клавиши доступа входят в переведённые названия пунктов меню, поэтому в разных языках они могут отличаться.

## Подключение к ЭБУ

| Сочетание | Действие |
|---|---|
| Ctrl+Shift+C | Подключиться к ЭБУ |
| Ctrl+Shift+D | Отключиться от ЭБУ |

## Навигация

| Сочетание | Действие |
|---|---|
| Ctrl+1–9 | Переключиться на вкладку 1–9 |
| Ctrl+Tab | Следующая вкладка |
| Ctrl+Shift+Tab | Предыдущая вкладка |
| Ctrl+W | Закрыть текущую вкладку |
| F11 | Переключить полноэкранный режим |

| Сочетание | Действие |
|---|---|
| Стрелки | Перемещение по ячейкам |
| Enter | Редактировать ячейку |
| Delete | Очистить ячейку |
| `=` | Уравнять (среднее значение) |
| `*` | Масштабировать выделение |
| `/` | Интерполировать |
| S | Сгладить выделение |
| Ctrl+A | Выделить всё |
| Ctrl+C | Копировать |
| Ctrl+V | Вставить |
| Ctrl+Shift+V | Специальная вставка |
| Ctrl+Z | Отменить |
| Ctrl+Y | Повторить |
| F | Переключить режим Follow |
| 3 | Переключить 3D-вид |

# Поддерживаемые ЭБУ

ЭБУ, совместимые с LibreTune.

## Официально поддерживаемые ЭБУ

Эти ЭБУ протестированы и полностью поддерживаются.

### Speeduino
Поддерживаются все версии прошивки Speeduino:
- серия Speeduino 202xxx;
- все варианты плат (UA4C, NO2C и другие);
- стандартная скорость обмена 115200 бод.

**Возможности:** полноценное редактирование таблиц, AutoTune, регистрация данных и все диагностические функции.

### rusEFI
Поддерживаются все варианты плат rusEFI:
- Proteus F4;
- Prometheus;
- MRE;
- платы Hellen;
- пользовательские платы.

**Возможности:** полная поддержка, включая расширенные функции.

### epicEFI
Поддерживаются все версии прошивки epicEFI:
- стандартные платы epicECU;
- обмен данными на скорости 115200 бод.

**Возможности:** полноценное редактирование таблиц, AutoTune и диагностика.

## Совместимые ЭБУ

Эти ЭБУ используют совместимый формат INI и должны работать с LibreTune.

### MegaSquirt
- **MS2**: базовая совместимость.
- **MS3**: базовая совместимость.
- **MS3 Pro**: базовая совместимость.

**Примечание:** некоторые расширенные функции MS могут поддерживаться не полностью.

### Другие ЭБУ с поддержкой INI
Любой ЭБУ, использующий стандартный формат INI, должен поддерживать:
- базовое редактирование таблиц;
- просмотр данных в реальном времени;
- управление файлами калибровок.

## Обнаружение ЭБУ

LibreTune определяет ЭБУ следующим образом:
1. Подключается к последовательному порту.
2. Запрашивает идентификатор (signature) ЭБУ.
3. Сравнивает его с загруженным INI-файлом.

Если идентификатор не совпадает:
- выполняется поиск подходящего INI локально;
- выполняется поиск в сетевых репозиториях;
- можно продолжить работу с предупреждением.

## Получение INI-файлов

### Встроенный репозиторий
LibreTune содержит распространённые INI-файлы:
- Speeduino (несколько версий);
- rusEFI (несколько плат);
- epicEFI.

### Поиск в Интернете
Поиск выполняется в репозиториях GitHub:
1. официальный репозиторий Speeduino;
2. официальный репозиторий rusEFI;
3. официальный репозиторий FOME;
4. автоматическая загрузка подходящего INI.

### Ручной импорт
1. Откройте **Настройки → Определения ЭБУ → Импорт**.
2. Выберите INI-файл.
3. Файл будет добавлен в локальный репозиторий.

## Добавление поддержки ЭБУ

Чтобы добавить поддержку нового ЭБУ:
1. Получите файл определения INI.
2. Импортируйте его в LibreTune.
3. Проверьте подключение и работу функций.
4. Сообщите о проблемах на GitHub.

Большинство ЭБУ с совместимым INI должны работать без изменений.

## Устранение неисправностей

### «Неизвестный идентификатор ЭБУ»
1. Убедитесь, что выбран правильный INI.
2. Попробуйте найти подходящий INI через онлайн-поиск.
3. Проверьте версию прошивки ЭБУ.

### «Ошибка связи»
1. Проверьте USB-подключение.
2. Проверьте скорость обмена (baud rate).
3. Попробуйте другой USB-порт.
4. Проверьте питание ЭБУ.

### «Функции не работают»
Для работы некоторых функций конкретного ЭБУ могут потребоваться:
- обновлённый INI-файл;
- обновление LibreTune;
- запрос на добавление функции.

## Шаблоны триггеров

### Как устроена поддержка шаблонов триггеров

**Важно:** шаблоны триггеров (например, «60-2», «36-1», «Nissan QG18») реализованы **в прошивке ЭБУ**, а не в LibreTune.

LibreTune считывает доступные шаблоны из INI-файла и отображает их в выпадающем списке. Фактическое декодирование сигнала триггера в реальном времени выполняет микроконтроллер ЭБУ.

### Если нужного шаблона триггера нет в списке

1. **Проверьте прошивку ЭБУ:** убедитесь, что ваша версия поддерживает этот шаблон.
2. **Обновите прошивку:** если поддержка появилась недавно, установите новую версию прошивки.
3. **Запросите добавление функции** у производителя ЭБУ:
   - Speeduino: https://speeduino.com/forum/
   - rusEFI: https://github.com/rusefi/rusefi
   - epicEFI: обратитесь через официальные каналы.
4. **Импортируйте новый INI:** после обновления прошивки импортируйте в LibreTune соответствующий INI.

**Пример:** для запроса поддержки используйте [шаблон обращения о шаблоне триггера](https://github.com/RallyPat/LibreTune/blob/main/.github/ISSUE_TEMPLATE/trigger_pattern_request.md).

### Временные решения

Пока прошивка не поддерживает нужный шаблон:
- используйте вариант «Custom toothed wheel» с ручной настройкой;
- используйте похожий шаблон, если характеристики синхронизации совпадают;
- используйте плату-преобразователь сигнала триггера.

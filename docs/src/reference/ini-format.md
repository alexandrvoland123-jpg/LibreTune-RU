# Формат INI-файлов

Описание файлов конфигурации ЭБУ.

## Обзор

INI-файлы задают:
- структуру памяти ЭБУ;
- константы конфигурации;
- таблицы и кривые;
- выходные каналы;
- настройки приборов;
- структуру меню.

## Структура файла

```ini
[MegaTune]
signature = "speeduino 202310"
queryCommand = "Q"
...

[Constants]
; Memory layout and defaults
...

[OutputChannels]
; Real-time data definitions
...

[TableEditor]
; Table definitions
...

[GaugeConfigurations]
; Gauge setup
...

[Menu]
; Menu structure
...
```

## Основные разделы

### [MegaTune]

Идентификация ЭБУ и команды:
```ini
signature = "speeduino 202310"
queryCommand = "Q"
versionInfo = "S"
```

### [Constants]

Значения, расположенные в памяти по заданным адресам:
```ini
page = 1
blockingFactor = 128
reqFuel = scalar, U08, 0, "ms", 0.1, 0, 0, 25.5
```

### [OutputChannels]

Данные, доступные в реальном времени:
```ini
rpm = scalar, U16, 0, "RPM", 1, 0
map = scalar, U16, 2, "kPa", 0.1, 0
```

### [TableEditor]

Определения таблиц:
```ini
table = veTable1Tbl, veTable1Map, "VE Table 1", 1
  xBins = rpmBins, rpm
  yBins = mapBins, map
  zBins = veTable1
```

## Типы данных

| Тип | Размер | Диапазон |
|---|---:|---:|
| U08 | 1 байт | 0–255 |
| S08 | 1 байт | −128…127 |
| U16 | 2 байта | 0–65535 |
| S16 | 2 байта | −32768…32767 |
| U32 | 4 байта | 0–4294967295 |
| F32 | 4 байта | Число с плавающей точкой |

## Выражения

В константах можно использовать выражения:
```ini
value = scalar, U08, 0, "", 1, 0, 0, { nCylinders * 2 }
```

Поддерживаемые операторы: `+`, `-`, `*`, `/`, `?:`, `&&`, `||`.

## Определение меню

Так задаются меню приложения:
```ini
menu = "Fuel"
  subMenu = veTable1Tbl, "VE Table 1"
  subMenu = reqFuelCalc, "Required Fuel"
  subMenu = injCharacteristics, "Injector Characteristics"
```

## Определение диалоговых окон

Экраны настроек формируются в разделе `[UserDefined]` из именованных диалогов, на которые ссылается `subMenu` (или которые встраиваются через `panel =`):

```ini
[UserDefined]
dialog = moreIgnitionOptions, "Ignition Options"
    field = "Use Prediction", use_prediction
    checkbox = "Use Prediction", use_prediction, { !use_prediction }
    checkbox = "Don't use Prediction", use_prediction, flipValue, { use_prediction }
    slider = "Prediction filter", predictionFilter, horizontal, { use_prediction }
```

Основные директивы: `field` (редактор константы с подписью), `checkbox` (переключатель, связанный с константой), `slider` (регулятор диапазона, использующий минимальное и максимальное значения самой константы), `panel` (встраивание другого диалога), `commandButton`, `settingSelector`, `gauge`, `indicator`, `runtimeValue`, `table`.

**Директивы checkbox.** Отображаются как обычные флажки, связанные с константой: по умолчанию установленный флажок соответствует ненулевому значению. Необязательный токен `flipValue` инвертирует логику (установленный флажок соответствует 0). Условия в фигурных скобках работают так же, как для полей: одно выражение включает или отключает элемент (он становится неактивным, но не скрывается); два выражения задают сначала видимость, затем доступность. Два флажка для одной константы с противоположными условиями работают как переключатель с взаимоисключающими вариантами — так же, как в TunerStudio.

**Директивы slider.** Отображаются как регулятор диапазона с границами, заданными минимальным и максимальным значениями константы. Записанное значение применяется после отпускания ползунка. Допускается необязательный параметр ориентации (`horizontal`/`vertical`); LibreTune в обоих случаях отображает регулятор горизонтально.

**Директивы displayOnlyField.** Это строки только для чтения. Если указана константа, отображается её текущее значение (для констант типа `bits` — текст варианта, например настроенный контакт). Если константа не указана или используется `blankfield`, отображается статическая текстовая строка; условия видимости и доступности применяются обычным образом. Префиксы подписи `#` и `!` оформляют строку как заголовок раздела или примечание.

**requiresPowerCycle.** Константы, перечисленные в `requiresPowerCycle` раздела `[ConstantsExtensions]`, помечаются в диалогах значком «требуется перезапуск питания»: изменение вступит в силу только после перезапуска ЭБУ.

**topicHelp.** Параметр `topicHelp = "https://…"` внутри определения диалога отображается в его заголовке как внешняя ссылка на справку.

## Определение приборов

Настройка приборов:
```ini
[GaugeConfigurations]
rpmGauge = rpm, "Engine Speed", "RPM", 0, 8000, 300, 600, 6500, 7500
```

Формат: канал, заголовок, единицы измерения, минимум, максимум, нижний порог предупреждения, нижний критический порог, верхний порог предупреждения, верхний критический порог.

## Изменение INI-файлов

**Предупреждение:** изменение INI-файлов может привести к проблемам:
- Неправильные смещения могут повредить данные.
- Неверно заданные типы приводят к ошибочному чтению значений.
- Всегда сохраняйте резервную копию оригинального файла.

Для пользовательских ЭБУ:
1. Начните с похожего существующего INI-файла.
2. Вносите изменения постепенно.
3. Проверяйте каждое изменение.
4. Документируйте внесённые правки.

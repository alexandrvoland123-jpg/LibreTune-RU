# Часто задаваемые вопросы

## Общие вопросы

### Какие ЭБУ поддерживает LibreTune?

LibreTune работает с любым ЭБУ, использующим стандартный формат описания INI:
- Speeduino (все версии);
- rusEFI (все платы);
- epicEFI (все версии);
- MegaSquirt MS2/MS3 (режим совместимости).

### LibreTune бесплатна?

Да. LibreTune — программа с открытым исходным кодом под лицензией GPL-2.0. Её можно бесплатно использовать, изменять и распространять свои модификации.

### Можно ли использовать существующие проекты TunerStudio?

Да. Выберите **Файл → Импорт проекта TS**, чтобы импортировать папку проекта TunerStudio вместе с калибровками, точками восстановления и настройками.

### Будут ли работать мои INI-файлы?

Да. LibreTune использует тот же формат INI, что и TunerStudio. Обычно существующие INI-файлы не требуют изменений.

### Может ли ИИ-ассистент самостоятельно настроить автомобиль?

Нет, и это сделано намеренно. ИИ-ассистент выступает в роли помощника: он может читать таблицы, анализировать логи и **предлагать** изменения, но не применяет их без явного подтверждения пользователя. Каждое предложение попадает в очередь проверки, где его можно принять или отклонить. Принятые изменения вносятся в рабочую калибровку (предварительно создаётся точка восстановления, чтобы можно было откатиться). Запись данных непосредственно в ЭБУ (Burn) всегда выполняется отдельно и вручную. Подробности приведены в разделе [ИИ-ассистент](./features/ai-assistant.md).

### Нужна ли учётная запись OpenAI для работы ИИ-ассистента?

Нет. Используется принцип **Bring Your Own LLM** — можно подключить OpenAI, Anthropic, Google или локальную модель (например, через Ollama), чтобы данные не покидали ваш компьютер. См. раздел [Провайдеры](./features/ai-assistant.md#провайдеры).

## Проблемы с подключением

### ЭБУ не отображается в списке портов

1. Проверьте подключение USB-кабеля.
2. Убедитесь, что на ЭБУ подано питание (светодиоды горят).
3. Установите USB-драйверы (CH340 или FTDI).
4. Нажмите **Обновить** в окне подключения.
5. Попробуйте другой USB-порт.

### Истекает время ожидания подключения

1. Убедитесь, что скорость обмена совпадает с настройками ЭБУ (обычно 115200 бод).
2. Проверьте, отвечает ли ЭБУ (индикаторы состояния мигают).
3. Попробуйте выключить и снова включить питание ЭБУ.
4. Проверьте разъёмы и соединения.

### Ошибка «Signature mismatch» (несовпадение сигнатуры)

INI-файл не соответствует прошивке ЭБУ:
1. Загрузите INI-файл для установленной версии прошивки.
2. Либо воспользуйтесь онлайн-поиском LibreTune, чтобы найти подходящий INI.
3. При необходимости обновите прошивку ЭБУ в соответствии с используемым INI.

### Отказано в доступе в Linux

Добавьте пользователя в группу `dialout`:

```bash
sudo usermod -a -G dialout $USER
```

Затем выйдите из системы и войдите снова.

## Редактирование таблиц

### Как отменить изменение?

Нажмите `Ctrl+Z`. LibreTune хранит полную историю изменений.

### Что делает команда «Задать одинаковое значение» (Set Equal)?

Set Equal (клавиша `=`) заменяет значения всех выделенных ячеек их средним значением. Это удобно для выравнивания участка таблицы.

### Что делает команда «Сгладить» (Smooth)?

Smooth (клавиша `S`) применяет гауссово сглаживание к выделенным ячейкам, уменьшая резкие переходы между соседними значениями.

### Как изменить значения осей?

Используйте функцию **Re-bin**:
1. Выберите таблицу.
2. Нажмите **Re-bin** на панели инструментов.
3. Введите новые значения осей.
4. Значения Z будут автоматически интерполированы.

## AutoTune

### AutoTune не изменяет ячейки

Проверьте фильтры:
- температура двигателя выше минимального порога (обычно 160 °F);
- обороты находятся в заданном диапазоне;
- TPS выше минимального значения;
- отсутствуют резкие изменения положения дросселя.

### Рекомендации слишком агрессивные

Уменьшите ограничения степени влияния:
- начните с максимального изменения 5–10 %;
- постепенно увеличивайте предел по мере улучшения базовой калибровки.

### Для некоторых ячеек не собираются данные

Проедьте в режимах, соответствующих этим ячейкам:
- удерживайте стабильный режим в каждой ячейке несколько секунд;
- включите движение с постоянной скоростью, лёгкое ускорение и частичную нагрузку.

## Регистрация данных

### Где сохраняются файлы логов?

Логи сохраняются в папке проекта, в каталоге `logs/`.

### В каком формате записываются логи?

LibreTune использует формат CSV, совместимый с MegaLogViewer и другими инструментами анализа.

### Как воспроизвести лог?

1. Откройте **Инструменты → Просмотр логов**.
2. Нажмите **Открыть лог**.
3. Выберите файл CSV.
4. Используйте элементы управления воспроизведением для пошагового просмотра данных.

## Проекты

### Где хранятся проекты?

По умолчанию: `~/Documents/LibreTuneProjects/`. Путь можно изменить в настройках.

### Как создать резервную копию проекта?

Проекты представляют собой обычные папки. Можно:
1. Использовать встроенную функцию **Точки восстановления**.
2. Включить **контроль версий Git** для хранения полной истории.
3. Просто скопировать папку проекта.

### Чем отличаются команды Save и Burn?

- **Save (Сохранить):** записывает калибровку в файл проекта на диске.
- **Burn (Записать в ЭБУ):** записывает калибровку во флеш-память ЭБУ.

Перед записью в ЭБУ всегда сохраняйте файл проекта.

## Производительность

### LibreTune медленно работает на компьютере

Попробуйте следующие настройки:
1. Отключите трёхмерную визуализацию таблиц.
2. Уменьшите частоту обновления приборов.
3. Отключите сглаживание изображения приборов.
4. Закройте неиспользуемые вкладки.

### Приборы обновляются рывками

1. Проверьте стабильность соединения с ЭБУ.
2. Уменьшите частоту опроса в настройках.
3. Закройте другие приложения, использующие последовательные порты.

## Шаблоны синхронизации (Trigger Patterns)

### Моего шаблона нет в списке

Шаблоны синхронизации (например, `60-2`, `36-1`, `Nissan QG18`) определяются **прошивкой ЭБУ**, а не LibreTune. Программа отображает только те варианты, которые доступны в вашем INI-файле.

Если нужного шаблона нет:
1. Проверьте, поддерживает ли его прошивка ЭБУ.
2. Запросите поддержку у разработчиков прошивки (Speeduino, rusEFI и т. д.).
3. Обновите прошивку, если поддержка появилась в новой версии.
4. Импортируйте соответствующий INI-файл в LibreTune.

Для оформления запроса используйте [шаблон обращения о поддержке шаблона триггера](https://github.com/RallyPat/LibreTune/blob/main/.github/ISSUE_TEMPLATE/trigger_pattern_request.md).

### Может ли LibreTune добавить поддержку моего шаблона?

Нет. Декодирование шаблона выполняется непосредственно прошивкой ЭБУ в реальном времени с точностью до микросекунд. LibreTune — интерфейс настройки на компьютере, он не обрабатывает сигналы датчика положения коленчатого вала.

Чтобы добавить новый шаблон:
1. Запросите его реализацию в проекте прошивки ЭБУ (Speeduino, rusEFI).
2. Дождитесь реализации в прошивке.
3. Обновите прошивку ЭБУ.
4. Импортируйте новый INI-файл.
5. После этого шаблон появится в LibreTune автоматически.

### Что делать, если шаблон нужен прямо сейчас?

Временные варианты:
- использовать режим «Custom toothed wheel» с ручной настройкой;
- выбрать похожий существующий шаблон, если временные характеристики достаточно близки;
- использовать плату-конвертер сигналов датчика;
- рассмотреть переход на ЭБУ, который уже поддерживает нужный шаблон.

# Начало работы: первый проект

LibreTune использует **файловый рабочий процесс**: вы непосредственно работаете с файлами калибровок, а проекты создаются автоматически для организации работы. Каждый проект содержит:
- определение ЭБУ (файл INI);
- текущую калибровку (`.msq`);
- резервные точки восстановления;
- историю версий (если она включена).

---

## Стартовый экран

Если при запуске LibreTune нет открытого проекта, отображается **стартовый экран** с тремя основными действиями и историей последних проектов.

### Основные действия

| Кнопка | Назначение |
|---|---|
| **Открыть файл калибровки** | Выбрать существующий файл калибровки `.msq` или `.xml`. Вокруг него автоматически создаётся проект. Это основной способ начать работу. |
| **Подключиться к ЭБУ** | Открыть окно подключения и напрямую соединиться с ЭБУ через последовательный порт. Удобно, если нужно считать калибровку непосредственно из ЭБУ. |
| **Импорт проекта TS** | Импортировать существующую папку проекта TunerStudio вместе с калибровкой, точками восстановления и настройками. |

Под основными действиями находится дополнительная ссылка:

- **Создать базовую карту по параметрам двигателя** — открыть [генератор базовой карты](../features/base-map.md), чтобы создать безопасную исходную калибровку по характеристикам двигателя (число цилиндров, рабочий объём, производительность форсунок и т. д.). Используйте эту функцию, если начинаете с нуля и у вас нет готового файла калибровки.

### Последние проекты

В нижней части экрана отображаются до 8 последних проектов. Нажмите на проект, чтобы сразу открыть его.

Для каждого проекта показываются:
- **Название проекта**;
- **сигнатура ЭБУ** (определение INI, которое используется проектом);
- **дата последнего изменения**;
- **кнопка удаления** (✕) справа.

#### Удаление проекта

Чтобы удалить проект со стартового экрана:
1. Нажмите кнопку **✕** справа от записи проекта.
2. Кнопка изменится на **✓ Подтвердить** — нажмите её ещё раз для окончательного удаления.
3. Папка проекта и всё её содержимое (калибровка, точки восстановления и история) будут удалены.

> **Предупреждение:** удаление проекта необратимо. Отменить его нельзя. Перед удалением убедитесь, что важные файлы калибровки сохранены в резервной копии.

Если вы случайно нажали ✕, щёлкните в другом месте или выберите другой проект, чтобы отменить удаление.

## Открытие файла калибровки

Это самый распространённый способ начать работу. Он подходит для файла, который вы скачали, получили от другого специалиста или ранее экспортировали.

### Пошаговая инструкция

1. Нажмите **Открыть файл калибровки** на стартовом экране либо выберите **Файл → Открыть файл калибровки...** (`Ctrl+N`).
2. В окне выбора файлов укажите файл калибровки `.msq` или `.xml`.
3. LibreTune прочитает файл и покажет **панель предварительного просмотра**:

| Поле | Описание |
|---|---|
| **Сигнатура** | Сигнатура прошивки ЭБУ, записанная в файле калибровки |
| **Константы** | Количество констант и параметров в файле |
| **Автор** | Автор калибровки, если эти сведения сохранены |
| **Размер** | Размер файла в КБ |

4. LibreTune **автоматически сопоставит** сигнатуру калибровки с определением ЭБУ (файлом INI) из локального репозитория:
   - если найдено **одно совпадение**, оно будет выбрано автоматически;
   - если найдено **несколько совпадений**, выберите нужное из раскрывающегося списка;
   - если **совпадений нет**, можно:
     - нажать **Импортировать определение ЭБУ...**, чтобы добавить нужный INI;
     - вручную выбрать файл из полного списка в разделе «── Все определения ──».

5. Название проекта автоматически формируется из имени файла калибровки. При необходимости измените его.
6. Нажмите **Открыть**, чтобы создать проект и начать настройку.

### Что происходит при открытии

После нажатия кнопки «Открыть»:
- в каталоге проектов создаётся папка (`~/Documents/LibreTuneProjects/`);
- файл калибровки копируется в проект;
- выбранное определение ЭБУ связывается с проектом;
- проект появляется в списке последних проектов.

### Поддерживаемые форматы файлов

| Формат | Расширение | Описание |
|---|---|---|
| MegaSquirt XML | `.msq` | Стандартный формат калибровок ЭБУ, используемый Speeduino, rusEFI, MegaSquirt и другими системами |
| XML Tune | `.xml` | Универсальные файлы калибровок в формате XML |

## Прямое подключение к ЭБУ

Чтобы считать текущую калибровку непосредственно из подключённого ЭБУ:
1. Нажмите **Подключиться к ЭБУ** на стартовом экране.
2. В окне подключения:
   - выберите **последовательный порт** (например, `/dev/ttyUSB0`, `COM3`);
   - установите **скорость передачи** (обычно 115200 для современных ЭБУ, 9600 для Speeduino).
3. Нажмите **Подключить**.
4. LibreTune считает сигнатуру ЭБУ и синхронизирует все страницы.
5. Если подходящий проект уже существует, он будет открыт повторно. В противном случае сначала может потребоваться создать проект через **Открыть файл калибровки**.

Подробная инструкция приведена в разделе [Подключение к ЭБУ](./connecting.md).

## Импорт проекта TunerStudio

Если вы переходите с TunerStudio:
1. Нажмите **Импорт проекта TS** на стартовом экране либо выберите **Файл → Импорт проекта TS...**.
2. Укажите папку проекта TunerStudio (обычно `~/TunerStudioProjects/` или `Documents\\TunerStudioProjects\\`).
3. В окне предварительного просмотра будут показаны:
   - название проекта (из `project.properties`);
   - определение INI;
   - текущая калибровка;
   - количество точек восстановления.
4. Нажмите **Импортировать**.
5. Проект будет создан и автоматически открыт.

Полное описание приведено в разделе [Импорт проектов](../projects/importing.md).

## Создание базовой карты

Если вы используете совершенно новый ЭБУ и у вас нет файла калибровки, можно создать безопасную исходную настройку:
1. Нажмите **Создать базовую карту по параметрам двигателя** на стартовом экране либо выберите **Инструменты → Создать базовую карту...**.
2. Введите характеристики двигателя:
   - количество цилиндров, рабочий объём, производительность форсунок;
   - тип топлива, тип наддува, режим впрыска и зажигания;
   - обороты холостого хода, предельные обороты, целевое давление наддува (для турбированного двигателя).
3. Нажмите **Создать базовую карту**.
4. Просмотрите сформированные таблицы (VE, зажигание, AFR, обогащения).
5. Нажмите **Использовать как начальную калибровку**, чтобы создать проект на основе этой карты.

Полное руководство: [Генератор базовой карты](../features/base-map.md).

## Управление определениями ЭБУ (файлами INI)

Файлы определения ЭБУ (INI) сообщают LibreTune, как интерпретировать данные калибровки. Необходимо использовать INI, соответствующий версии прошивки вашего ЭБУ.

### Откуда берутся INI-файлы
- **Загружаются автоматически**, когда LibreTune обнаруживает несовпадение сигнатуры и находит подходящий файл в Интернете.
- **Импортируются вручную** через **Настройки → Определения ЭБУ** или при открытии файла калибровки.
- **Входят в состав** некоторых импортируемых проектов TunerStudio.

### Управление библиотекой INI

Откройте **Настройки** (`Ctrl+Comma`) и перейдите на вкладку **Определения ЭБУ**:
- просматривайте импортированные INI-файлы, их названия и сигнатуры;
- добавляйте новые INI с помощью кнопки импорта;
- удаляйте ненужные INI кнопкой ✕ (нажмите один раз для выбора, второй — для подтверждения).

Подробнее: [Настройки — Определения ЭБУ](./settings.md#описания-эбу).

## Переключение между проектами

Чтобы перейти к другому проекту:
1. Выберите **Файл → Закрыть проект**.
2. Появится стартовый экран со списком последних проектов.
3. Выберите проект, чтобы открыть его, или начните новый.

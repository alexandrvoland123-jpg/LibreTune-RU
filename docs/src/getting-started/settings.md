# Настройки и предпочтения

Настройка поведения LibreTune, параметров подключения и отображения.

## Открытие настроек

**File → Settings** (or **Ctrl+Comma**)

Диалог Settings содержит несколько вкладок с различными параметрами.

### Поиск настройки

**Поле поиска** в правой верхней части заголовка диалога фильтрует настройки **на всех вкладках** по мере ввода — так же, как поиск в боковой панели. При поиске:

- панель вкладок скрывается, а подходящие разделы *всех* вкладок отображаются единым списком;
- поиск выполняется по всем подписям, вариантам раскрывающихся списков и справочным примечаниям — знать, на какой вкладке находится настройка, не нужно;
- если совпадений нет, отображается сообщение **«No settings found»**.

Очистите поле (или нажмите ✕), чтобы вернуться к обычному виду с вкладками.

## Язык

Селектор **Language** на вкладке **General** позволяет выбрать язык интерфейса LibreTune.
Поддерживаемые языки:

- **Английский** (по умолчанию / резервный вариант)
- **Португальский (Бразилия)**
- **Венгерский (Magyar)**

После смены языка сразу переводятся **меню приложения** (File, Edit, View, Tools, Help) и **подсказки панели инструментов**. Меню настройки ЭБУ (Fuel, Ignition и т. д.) **не переводятся**: их названия берутся непосредственно из INI-файла вашего ЭБУ и отображаются без изменений, поскольку относятся к содержимому ЭБУ, а не к интерфейсу приложения.

> **Добавление языка:** скопируйте `crates/libretune-app/src/i18n/locales/en/` в новую папку `<code>/`, переведите все значения (ключи должны остаться неизменными) и зарегистрируйте язык в `i18n/index.ts` и в списке выбора языка диалога Settings.

## Расположение строки меню

### Группировка меню

Верхняя строка меню разделена визуальными разделителями на три группы:

```
File  Edit  View  Tools   │   <ECU tuning menus>   │   Help
└─── application menus ──┘   └── from the INI ──┘   └── rightmost
```

- **Меню приложения** (File, Edit, View, Tools) переводятся и сохраняют постоянное расположение независимо от подключённого ЭБУ.
- **Меню настройки ЭБУ** (Fuel, Ignition и т. д.) берутся из INI и различаются для разных ЭБУ. Они расположены между меню приложения и Help.
- **Help** всегда находится справа, где пользователи обычно ожидают его увидеть.

У каждого меню есть **клавиша доступа** (подчёркнутая буква): нажмите `Alt` и эту букву, чтобы открыть меню (например, `Alt+F` для File, `Alt+T` для Tools).

### Отображение меню ЭБУ в строке меню

**Appearance → Layout → "Show ECU menus in menu bar"** (default: on)

Если вы предпочитаете более компактную строку меню, снимите флажок, чтобы **скрыть меню настройки ЭБУ в верхней строке**. Они останутся доступны в **боковой панели** — постоянной сворачиваемой панели навигации слева. Управление боковой панелью: **View → Toggle Sidebar**.

## Настройки подключения

Настройте способ обмена данными между LibreTune и ЭБУ.

### Последовательный порт

**Выбор порта:**
- Раскрывающийся список доступных последовательных портов.
- COM3, COM4 (Windows)
- /dev/ttyUSB0, /dev/ttyACM0 (Linux)
- /dev/ttyUSB0 (macOS)

**Скорость передачи (Baud Rate):**
- 9600 — Speeduino и старые ЭБУ.
- 115200 — современные ЭБУ, rusEFI, FOME.
- Доступен ввод пользовательской скорости.
- По умолчанию: автоматическое определение по INI.

**Автоматическое подключение:**
- Включите, чтобы подключаться при запуске приложения.
- Перед этим необходимо выбрать проект.
- Полезно при разработке и отладке.

### Поведение подключения

**Тайм-аут (секунды):**
- Время ожидания ответа.
- По умолчанию: 5 секунд.
- Для медленных соединений увеличьте значение.
- Для более быстрой реакции уменьшите значение.

**Повторное подключение при ошибке:**
- Автоматические попытки повторного подключения.
- Количество попыток: 3–10.
- Задержка между попытками: 100–1000 мс.

**Поддержание соединения (Keep Alive):**
- Периодическая проверка состояния.
- Помогает предотвратить потерю соединения.
- По умолчанию: каждые 10 секунд.

## Настройки отображения

**Тёмная тема** (по умолчанию)
- Тёмный интерфейс.
- Уменьшает нагрузку на глаза.
- Удобнее при освещении гаража.

**Светлая тема**
- Стандартный светлый интерфейс.
- Некоторым пользователям удобнее на улице.
- Среди настройщиков используется реже.

### Размер шрифта

**Маленький:** 12 px (больше информации помещается на экране).
**Средний:** 14 px (по умолчанию, удобен для чтения).
**Большой:** 16 px (вариант для повышения доступности).

### Сетка редактора таблиц

**Высота строки:**
- Компактная: 20 px (больше строк на экране).
- Обычная: 28 px (по умолчанию).
- Просторная: 36 px (удобнее выбирать ячейки).

**Ширина столбца:**
- Авто: по содержимому.
- Фиксированная: столбцы шириной 60 px.
- Пользовательская: задаётся вручную.

**Подсветка активной ячейки:**
- Включено: показывает выбранную ячейку.
- Цвета: настройка цвета выделения.
- Непрозрачность: 50–100%.

**Звук навигации с клавиатуры:**
- Включение/выключение звука щелчка при перемещении между ячейками.
- Громкость: без звука, тихая, обычная, высокая.

### Строка состояния

**Показывать строку состояния:**
- Отображает сведения о подключении и каналах.
- Располагается в нижней части окна.
- Может быть включена или выключена.

**Каналы строки состояния:**
- Каналы для отображения можно выбирать.
- Одновременно отображается не более 8 каналов.
- Перетаскивайте каналы, чтобы изменить порядок.

## Описания ЭБУ

Вкладка **ECU Definitions** позволяет управлять библиотекой INI-файлов. В этих файлах описано, как LibreTune должна обмениваться данными с конкретной версией прошивки вашего ЭБУ.

### Просмотр импортированных описаний

На вкладке отображается прокручиваемый список всех INI-файлов в локальном хранилище. Для каждой записи показаны:
- **Name** — имя INI-файла (например, `speeduino202310.ini`);
- **Signature** — строка сигнатуры прошивки ЭБУ, которой соответствует INI.

### Импорт нового INI-файла

1. Нажмите кнопку **Import ECU Definition** в верхней части списка.
2. Выберите файл `.ini` на компьютере.
3. Файл будет скопирован в каталог описаний LibreTune.
4. Он сразу появится в списке и станет доступен при создании проектов.

Импортировать INI-файлы также можно:
- во время процесса [Open Tune File](./first-project.md#открытие-файла-калибровки), если подходящий INI не найден;
- автоматически, когда LibreTune загружает подходящий INI из онлайн-репозитория.

### Удаление INI-файла

Чтобы удалить ненужное описание INI:

1. Нажмите кнопку **✕** рядом с записью INI.
2. Кнопка изменится на **Confirm** — нажмите её ещё раз для окончательного удаления.
3. INI-файл будет удалён из локального хранилища.

> **Примечание:** удаление INI не влияет на существующие проекты, которые уже используют этот файл. Однако для создания новых проектов с этим INI его потребуется импортировать повторно.

### Расположение файлов описаний

INI-файлы хранятся в каталоге данных приложения:
- **Linux**: `~/.local/share/LibreTune/definitions/`
- **macOS**: `~/Library/Application Support/LibreTune/definitions/`
- **Windows**: `%APPDATA%\LibreTune\definitions\`

## Контроль версий

Настройка интеграции с Git для контроля версий калибровки.

### Включение контроля версий

**Настройки автоматических коммитов:**
- **Never:** только ручные коммиты.
- **Always:** автоматический коммит после каждого сохранения.
- **Ask:** перед сохранением появляется диалог подтверждения.

**Шаблон сообщения коммита:**
```
{date} {time} - Tuned {table}
```

Доступные подстановки:
- `{date}` — YYYY-MM-DD
- `{time}` — HH:MM:SS
- `{table}` — имя таблицы
- `{user}` — имя пользователя
- `{message}` — пользовательское сообщение

### Управление ветками

**Ветка по умолчанию:**
- Обычно `main` или `master`.
- Для экспериментов можно создавать новые ветки.

**Автоматическая очистка веток:**
- Удалять старые ветки через заданное количество дней.
- Поддерживает порядок в репозитории.
- По умолчанию: 30 дней.

## ИИ-ассистент

**ИИ-ассистент** — помощник на основе языковой модели, которую предоставляет пользователь. Он может помогать настраивать и конфигурировать ЭБУ. Подробности см. в разделе [ИИ-ассистент](../features/ai-assistant.md).

> ⚠️ **Используйте на свой риск.** Ассистент только *предлагает* изменения; ничего не применяется и не записывается в ЭБУ автоматически.

### Включение

1. Scroll to the **AI Assistant (at your own risk)** section.
2. Прочитайте предупреждение о рисках и установите флажок подтверждения.
3. Настройте провайдера (см. ниже).
4. Check **Enable AI Assistant**.
5. Click **Apply** (save without closing) or **OK** (save and close).

### Провайдер

- **OpenAI** — облачный OpenAI или любая совместимая конечная точка (OpenRouter, Ollama, LM Studio, vLLM).
- **Anthropic** — модели Claude.
- **Google** — модели Gemini.

Раскрывающийся список **Preset** одним нажатием заполняет провайдера, базовый URL и рекомендуемую модель. Доступны и локальные варианты (Ollama, LM Studio), при использовании которых данные калибровки остаются на этом компьютере.

### Базовый URL

Оставьте поле пустым, чтобы использовать адрес провайдера по умолчанию. Для локальной модели укажите её адрес, например `http://localhost:11434/v1` для Ollama.

### API-ключ

Ключ доступа к провайдеру. Для локальных конечных точек без аутентификации необязателен. Если системное хранилище ключей доступно, ключ сохраняется в нём (Windows Credential Manager, macOS Keychain, Linux Secret Service), а не в файле настроек. Если системное хранилище недоступно, LibreTune использует файл настроек, чтобы ассистент продолжал работать.

### Модель

Модель с поддержкой вызова инструментов/функций (например, `gpt-4o`, `claude-3-5-sonnet-20241022`, `gemini-1.5-pro`).

### Уровень возможностей

Уровни накапливаются: каждый следующий включает предыдущий.

- **Read — только просмотр и диагностика:** объяснение и анализ; предложения изменений недоступны.
- **Tune — чтение и предложения по таблицам:** изменения ячеек и пакетные операции.
- **Config — настройка и предложения по константам:** константы и переключатели функций; изменения, влияющие на контакты, помечаются как **Dangerous**.

### Локальный MCP-сервер

Предоставляет внешним MCP-клиентам (Claude Code, Claude Desktop и др.) инструменты LibreTune только для чтения и только через адрес `127.0.0.1`. По умолчанию выключен и не позволяет ничего изменять — см. [MCP-сервер](../features/mcp-server.md).

- **Expose tools over MCP** — запускает или останавливает сервер; во время работы рядом отображается адрес привязки.
- **Port** — минимальное значение 1024, по умолчанию 8765. Кнопка **Apply port** перезапускает сервер.
- **Access token** — bearer-токен, который должен отправлять каждый клиент. Кнопка **Show** показывает его, а **Regenerate** немедленно делает старый токен недействительным.

Эти три параметра применяются сразу, а не после нажатия **OK**, поскольку каждый из них открывает или закрывает реальный сетевой сокет.

## Настройки регистрации данных

### Регистратор данных

**Частота записи по умолчанию:** 10 Hz (10 выборок в секунду).
- Диапазон: от 1 до 100 Hz.
- Чем выше частота, тем подробнее данные, но тем больше размер файлов.
- Чем ниже частота, тем дольше может длиться сеанс.

**Каналы по умолчанию:**
- Выберите каналы, которые будут записываться по умолчанию.
- Для каждого журнала можно задать свой набор каналов.

**Расположение журналов:**
- Сохранение в папку проекта `/logs/` (по умолчанию).
- Можно выбрать другое расположение.

**Автосохранение:**
- Автоматически сохранять журнал после остановки (по умолчанию включено).
- Формат имени файла: `YYYY-MM-DD_HH-MM-SS.csv`.

### Срок хранения файлов

**Хранить журналы:** 30 дней (по умолчанию).
- Более старые файлы удаляются автоматически.
- Функцию можно отключить.
- Влияет на использование дискового пространства.

## Дополнительные настройки

### Проверка данных

**Предупреждать о выходе за пределы:**
- Включить предупреждения при вводе значений за пределами обычного диапазона.
- Помогает предотвратить случайный ввод некорректных данных.

**Предупреждать о больших изменениях:**
- Предупреждать, если изменение ячейки превышает порог.

- Помогает обнаруживать ошибки ввода.

**Автоматическая нормализация:**
- Автоматически ограничивать значения допустимым диапазоном.

- Опытные пользователи могут отключить эту функцию.

### Клавиатура

**Скорость повтора клавиш:**
- Быстрая (короткая задержка).

**Поведение выделения:**
- Один щелчок — выбрать.

### Сеть

**Проверка обновлений:**
- При запуске (по умолчанию).
- Вручную.
- Никогда (отключить проверку).

**Загрузка документации для работы без сети:**
- Включите, чтобы руководство было доступно без подключения к Интернету.
- Требуется для некоторых вариантов развёртывания.

---

## Сброс к настройкам по умолчанию

**Сбросить все настройки:**
- Кнопка находится в нижней части окна настроек.
- Восстанавливает все исходные значения.
- Предупреждение: действие нельзя отменить.

**Сбросить отдельный раздел:**
- Сбрасывает только одну категорию.
- Остальные настройки не меняются.
- Используйте, если возникли проблемы с определённой категорией настроек.

## Сочетания клавиш

Основные сочетания клавиш, связанные с настройками:
- `Ctrl+,` - Открыть настройки
- `Ctrl+Z` - Отменить действие (в редакторах таблиц)
- `Ctrl+Y` - Повторить действие
- `Tab` - Следующее поле
- `Shift+Tab` - Предыдущее поле

## Советы по настройке

### Первоначальная настройка

1. Настройте подключение (порт, скорость передачи).
2. Выберите тему и размер шрифта.
3. Выберите единицы измерения (°C/°F, PSI/kPa).
4. Настройте параметры AutoTune по умолчанию.
5. Включите контроль версий (рекомендуется).

### Подготовка к сеансу настройки

1. Убедитесь, что параметры подключения заданы правильно.
2. Выберите удобный размер шрифта и отображения.
3. Убедитесь, что единицы измерения соответствуют характеристикам автомобиля.
4. Проверьте значения фильтров AutoTune по умолчанию.
5. Проверьте скорость повтора клавиш.

### Резервное копирование настроек

Настройки автоматически сохраняются в следующих каталогах:
- Windows: `%APPDATA%\LibreTune\`
- macOS: `~/Library/Application Support/LibreTune/`
- Linux: `~/.local/share/LibreTune/`

Для резервного копирования вручную скопируйте эту папку.

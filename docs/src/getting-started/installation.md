# Установка

LibreTune доступна для Windows, macOS и Linux.

## Загрузка

Загрузите последнюю версию для своей операционной системы со страницы [GitHub Releases](https://github.com/RallyPat/LibreTune/releases).

| Платформа | Файл |
|---|---|
| Windows | `LibreTune_x.x.x_x64-setup.exe` |
| macOS (Apple Silicon) | `LibreTune_x.x.x_aarch64.dmg` |
| macOS (Intel) | `LibreTune_x.x.x_x64.dmg` |
| Linux (Debian/Ubuntu) | `libretune_x.x.x_amd64.deb` |
| Linux (AppImage) | `LibreTune_x.x.x_amd64.AppImage` |

Сборки для macOS **не являются универсальными**. Загрузите файл, соответствующий процессору вашего Mac. Для компьютеров Apple Silicon (M1 и новее) нужен DMG-файл `aarch64`. Версия `x64` работает через Rosetta 2 и не запустится, если Rosetta не установлена.

## Установка в Windows

1. Загрузите установочный файл `.exe`.
2. Запустите его и следуйте инструкциям установщика.
3. LibreTune появится в меню «Пуск».

### Установка USB-драйверов в Windows

Для Speeduino и большинства ЭБУ на базе Arduino может потребоваться установка USB-драйверов:

1. Загрузите [драйверы CH340](https://sparks.gogo.co.nz/ch340.html) для совместимых плат Arduino.
2. Либо установите [драйверы FTDI](https://ftdichip.com/drivers/vcp-drivers/) для оригинальных плат Arduino.
3. Подключите ЭБУ и убедитесь, что в «Диспетчере устройств» он отображается как COM-порт.

## Установка в macOS

1. Загрузите файл `.dmg` для своего процессора (см. таблицу выше).
2. Откройте DMG и перетащите LibreTune в папку «Программы».
3. При первом запуске macOS может заблокировать приложение, поскольку оно не прошло нотариальную проверку Apple. Инструкции приведены ниже.

### Первый запуск в macOS (Gatekeeper)

Релизы LibreTune подписаны временной подписью, но не подписаны сертификатом Apple Developer ID и не прошли нотариальную проверку. Поэтому macOS помечает приложение как загруженное из Интернета и может показать сообщение «LibreTune cannot be opened because it is from an unidentified developer» или «LibreTune is damaged and can't be opened».

Это не означает, что приложение повреждено. Чтобы разрешить запуск:

1. Попробуйте открыть LibreTune двойным щелчком и закройте предупреждение.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите страницу до раздела «Безопасность» и нажмите **Всё равно открыть** рядом с сообщением о LibreTune.
4. Подтвердите действие кнопкой **Открыть**.

Если кнопка **Всё равно открыть** не появилась, удалите атрибут карантина через Терминал:

```bash
xattr -dr com.apple.quarantine /Applications/LibreTune.app
```

Выполняйте эту команду только для файлов, которым доверяете.

### Разрешения USB в macOS

macOS обычно автоматически распознаёт большинство USB-адаптеров последовательного порта. Если возникли проблемы:

1. Проверьте раздел **Системные настройки → Конфиденциальность и безопасность → Файлы и папки**.
2. Убедитесь, что LibreTune разрешён доступ к съёмным томам.

## Установка в Linux

### Debian/Ubuntu (.deb)

```bash
sudo dpkg -i libretune_x.x.x_amd64.deb
sudo apt-get install -f  # Установка зависимостей при необходимости
```

### AppImage

```bash
chmod +x LibreTune_x.x.x_amd64.AppImage
./LibreTune_x.x.x_amd64.AppImage
```

### Разрешения USB в Linux

Чтобы обращаться к последовательным портам без прав суперпользователя, добавьте свою учётную запись в группу `dialout`:

```bash
sudo usermod -a -G dialout $USER
```

Для применения изменений выйдите из системы и войдите снова.

## Обновление

После запуска LibreTune один раз проверяет наличие новой версии. Проверка не блокирует работу программы. Если обновление доступно, появится краткое уведомление. Кроме того, в меню **Справка → О LibreTune** есть кнопка **Установить и перезапустить**, а также команда **Проверить обновления**.

Загрузка и установка не начинаются, пока вы не нажмёте соответствующую кнопку.

Обновления имеют криптографическую подпись. Открытый ключ встроен в приложение. Если подпись обновления не проходит проверку, установка отменяется. Эта проверка не связана с нотариальной проверкой macOS и подписью издателя Windows: проект пока не использует их. Поэтому при первой установке в macOS всё ещё может потребоваться команда **Всё равно открыть**, а в Windows — **Подробнее → Выполнить в любом случае**.

Официальные сборки, включая ночные, содержат открытый ключ релиза. Самостоятельно собранная версия без этого ключа может обнаружить новое обновление, но загрузка будет отклонена при проверке подписи и ничего не установится.

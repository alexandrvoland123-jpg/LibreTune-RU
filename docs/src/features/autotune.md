# AutoTune — автоматическая настройка

AutoTune автоматически формирует рекомендации по настройке на основе показаний широкополосного датчика кислорода.

## Обзор

AutoTune отслеживает работу двигателя в реальном времени и предлагает корректировки таблицы VE, чтобы добиться заданных значений AFR. Это быстрый способ выполнить базовую настройку топливной таблицы.

## Что требуется

- Широкополосный датчик кислорода, подключённый к ЭБУ.
- Настроенная в ЭБУ таблица целевого AFR.
- Работающий и прогретый до рабочей температуры двигатель.

## Запуск AutoTune

1. Подключитесь к ЭБУ.
2. Откройте **Инструменты → AutoTune** или нажмите `Ctrl+Shift+A`.
3. Выберите таблицу для настройки (обычно VE Table 1).
4. Настройте параметры.
5. Нажмите **Старт**.

## С чего начать

Если вы впервые используете AutoTune, начните с [руководства по использованию](./autotune/usage-guide.md). В нём пошагово описаны:
- подготовка и меры безопасности;
- полный порядок работы — от первоначальной настройки до применения изменений;
- примеры для атмосферных, турбированных двигателей и двигателей на E85;
- устранение распространённых проблем.

## Интерфейс AutoTune

| Раздел | Описание |
|---|---|
| **Текущая таблица** | Существующие значения VE |
| **Рекомендации** | Предлагаемые корректировки |
| **Тепловая карта** | Визуализация охвата настройки |
| **Статистика** | Количество попаданий в ячейки и качество данных |

## Настройки

### Источник целевого AFR
- **Из таблицы:** использовать таблицу целевого AFR из ЭБУ.
- **Фиксированное значение:** использовать постоянное целевое значение (например, 14.7:1).

### Контроллер обновления
При включении рекомендации автоматически отправляются в ЭБУ.

### Ограничения степени влияния

| Параметр | Описание |
|---|---|
| **Максимальное увеличение** | Максимальный процент увеличения значения любой ячейки |
| **Максимальное уменьшение** | Максимальный процент уменьшения значения любой ячейки |
| **Абсолютный максимум** | Максимальное абсолютное изменение за одно обновление |

## Фильтры

Фильтры не позволяют некорректным данным влиять на рекомендации:

| Фильтр | Описание | По умолчанию |
|---|---|---|
| **Минимальные RPM** | Игнорировать данные ниже указанной частоты вращения | 800 |
| **Максимальные RPM** | Игнорировать данные выше указанной частоты вращения | 6500 |
| **Минимальная CLT** | Игнорировать данные при холодном двигателе | 160°F |
| **Минимальная TPS** | Игнорировать данные при закрытой дроссельной заслонке | 1% |
| **Максимальная скорость изменения TPS** | Игнорировать быстрые изменения положения дросселя | 10%/с |
| **Исключать обогащение при ускорении** | Игнорировать данные во время переходного обогащения | Да |

## Как понимать рекомендации

### Цветовая индикация
- **Синий:** рекомендуется добавить топливо (смесь бедная).
- **Красный:** рекомендуется убрать топливо (смесь богатая).
- **Серый:** данных недостаточно.

### Режимы тепловой карты

#### Вес ячейки
Показывает, сколько данных собрано для каждой ячейки:
- яркая ячейка — много данных, высокая достоверность;
- тусклая ячейка — мало данных, низкая достоверность.

#### Изменение ячейки
Показывает величину рекомендуемой корректировки:
- яркая ячейка — требуется большая корректировка;
- тусклая ячейка — корректировка небольшая.

## Порядок работы

1. Прогрейте двигатель до рабочей температуры.
2. Запустите AutoTune с консервативными ограничениями степени влияния.
3. Двигайтесь в обычном режиме, охватывая разные точки RPM/нагрузки.
4. Следите за заполнением тепловой карты.
5. Применяйте рекомендации, когда убедитесь в их достоверности.
6. Повторяйте процедуру, постепенно увеличивая степень влияния по мере улучшения базовой калибровки.

## Советы

### Обеспечьте достаточный охват
- Удерживайте двигатель в каждой ячейке несколько секунд в установившемся режиме.
- Охватите все сочетания RPM и нагрузки, которые будут использоваться.
- Включайте режимы движения с постоянной скоростью и плавным ускорением.

### Начинайте с небольших корректировок
- Начните с низких ограничений степени влияния (5–10%).
- Увеличивайте их по мере улучшения базовой калибровки.
- Большие корректировки могут указывать на проблемы в исходной настройке.

### Следите за выбросами
- Единичные скачки автоматически отфильтровываются.
- Постоянные показания бедной или богатой смеси обычно указывают на реальную проблему.
- Если все ячейки показывают бедную смесь, проверьте двигатель на подсос воздуха.

## Применение изменений

1. Проверьте рекомендации в таблице.
2. Нажмите **Отправить в ЭБУ**, чтобы применить изменения без сохранения в файл.
3. Либо нажмите **Применить и сохранить**, чтобы обновить файл калибровки.
4. Выполните **Burn**, чтобы записать изменения в энергонезависимую память ЭБУ.

## Блокировка ячеек

Заблокируйте ячейки, которые AutoTune не должен изменять:
1. Выберите ячейки в таблице рекомендаций.
2. Щёлкните правой кнопкой мыши и выберите **Заблокировать выбранные ячейки**.
3. Заблокированные ячейки отмечаются значком 🔒.

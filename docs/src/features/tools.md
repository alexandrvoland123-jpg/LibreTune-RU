# Инструменты

Дополнительные функции для сравнения калибровок, управления действиями и организации рабочих процессов настройки.

## Сравнение таблиц

Сравнивайте таблицы рядом, чтобы увидеть различия между версиями калибровки.

### Обзор

Сравнение таблиц позволяет:
- увидеть точные различия между отдельными ячейками;
- определить, какие ячейки изменились между версиями;
- проследить развитие калибровки по итерациям;
- оценить величину корректировок;
- экспортировать отчёты сравнения.

### Открытие сравнения таблиц

1. Перейдите в **Tools → Table Comparison**.
2. Выберите таблицы для сравнения.
3. Выберите тип сравнения (значения, проценты или разница).
4. Просмотрите результаты.

### Типы сравнения

#### Значения ячеек

Показывает фактические числовые значения в каждой таблице:
```
         Baseline    Tuned      Difference
RPM 3000
Load 50%    75.2       82.1        +6.9
```

#### Проценты

Показывает процентное изменение относительно исходной версии:
```
         Baseline    Tuned      % Change
RPM 3000
Load 50%    75.2       82.1       +9.2%
```

#### Тепловая карта

Цветовая визуализация изменений:
- 🟦 Синий — смесь богаче (добавлено топливо).
- 🟥 Красный — смесь беднее (топливо убрано).
- ⬜ Серый — без изменений.

### Порядок сравнения

**Шаг 1. Загрузите исходную калибровку.**
- Нажмите «Load Baseline».
- Выберите первый файл калибровки.
- Выберите таблицу для сравнения.

**Шаг 2. Загрузите изменённую версию.**
- Нажмите «Load Comparison».
- Выберите второй файл калибровки.
- Выберите ту же таблицу.

**Шаг 3. Изучите результаты.**
- Найдите большие различия.
- Определите закономерности корректировок.
- Проверьте согласованность изменений.

**Шаг 4. Экспортируйте результат.**
- Нажмите «Export Comparison».
- Выберите формат (PDF, Excel, CSV).
- Файл будет сохранён с временной меткой.

### Примеры использования

#### Проверка результатов AutoTune
```
Загрузите калибровку ДО AutoTune
Загрузите ту же калибровку ПОСЛЕ сеанса AutoTune
Сравните таблицы и посмотрите, какие рекомендации были применены
Проверьте обоснованность изменений
```

#### Документирование развития калибровки
```
Исходная калибровка (заводская)
    ↓ сравнение
Версия 1 (первый сеанс)
    ↓ сравнение
Версия 2 (второй сеанс)
    ↓ сравнение
Итоговая калибровка
```

#### Поиск проблемных областей
```
Загрузите эталонную калибровку (с диностенда)
Загрузите свою калибровку
Сравните их, чтобы найти отклонения
Изучите большие различия
```

#### Проверка до и после изменений
```
До изменения: исходная калибровка
После изменения: настроенная версия
Сравните их, чтобы подтвердить изменения
Задокументируйте результат
```

## Менеджер действий

Записывайте и повторно выполняйте действия настройки для документирования и воспроизводимости.

### Обзор

Менеджер действий записывает:
- редактирование таблиц (изменения ячеек);
- рекомендации AutoTune;
- сохранение калибровок;
- запись данных в ЭБУ (Burn);
- изменение настроек.

### Когда использовать

- **Документирование изменений:** сохраняйте историю выполненной настройки.
- **Повторное выполнение:** применяйте те же изменения к новой калибровке.
- **Совместная работа:** делитесь шагами настройки с другими.
- **Обучение:** показывайте, как создавалась калибровка.
- **Анализ:** изучайте историю разработки калибровки.

### Порядок работы

#### Запись действий

1. **Откройте Action Manager.**
   ```
   Tools → Action Manager
   ```
2. **Нажмите Record.**
   - Менеджер начинает отслеживать все изменения.
   - В статусе отображается «Recording…».
   - Продолжайте обычную настройку.
3. **Выполняйте настройку.**
   - Редактируйте ячейки таблиц.
   - Запускайте AutoTune.
   - Сохраняйте калибровки.
   - Записывайте данные в ЭБУ.
   - Все эти действия будут записаны.
4. **Остановите запись.**
   - По завершении нажмите **Stop**.
   - Действия сохраняются с временной меткой.
   - Сеансу можно присвоить имя.

#### Повторное выполнение действий

1. **Загрузите файл действий.**
   - Нажмите **Load Actions**.
   - Выберите файл `.actions`.
   - Сеанс будет загружен.
2. **Проверьте действия.**
   - Просмотрите список записанных действий.
   - Проверьте порядок и подробности.
   - Ненужные шаги можно пропустить.
3. **Запустите воспроизведение.**
   - Нажмите **Play**.
   - Действия применяются автоматически.
   - Доступны пауза и продолжение.
   - При необходимости воспроизведение можно повторить.

### Типы действий

| Действие | Описание | Подробности |
|---|---|---|
| Cell Edit | Изменение одной ячейки | RPM, Load, старое и новое значения |
| Table Operation | Массовое редактирование (scale, smooth) | Таблица, операция, параметры |
| AutoTune | Применение рекомендаций | Таблица, количество изменённых ячеек |
| Save | Сохранение файла калибровки | Имя файла, временная метка |
| Burn | Отправка данных в ЭБУ | Тип ЭБУ, успех/ошибка |
| Setting | Изменение параметра | Имя параметра, старое и новое значения |

### Примеры рабочих процессов

#### Пример 1. Документирование сеанса настройки
```
1. Откройте Action Manager → Record
2. Откройте AutoTune и выполните сеанс настройки
3. Примените рекомендации
4. Сохраните калибровку
5. Остановите запись
6. Назовите сеанс: "2024-02-03_autotune_session"
7. Экспортируйте его для обмена
```

#### Пример 2. Создание шаблона настройки
```
1. Запишите эталонный сеанс настройки
2. Сохраните действия как шаблон
3. Загрузите шаблон для новой калибровки
4. Воспроизведите все действия
5. Пользовательские изменения будут применены автоматически
```

#### Пример 3. Проверка изменений
```
1. Загрузите файл действий из сеанса настройки
2. Просмотрите все внесённые изменения
3. Рассчитайте общий объём корректировок
4. Задокументируйте результат
5. Поделитесь методикой с другими
```

### Экспорт действий

**Доступные форматы:**
- **`.actions`** — собственный формат, поддерживающий повторное выполнение.
- **`.txt`** — журнал в текстовом виде, удобном для чтения.
- **`.pdf`** — оформленный отчёт с анализом.

**Порядок экспорта:**
1. Запишите или загрузите действия.
2. Нажмите **Export**.
3. Выберите формат.
4. Нажмите **Save**.

### Настройки действий

**Автоматическая запись:**
- Включите её, чтобы запись запускалась автоматически.
- Полезно для продолжительных сеансов настройки.
- Режим можно включать и выключать по мере необходимости.

**Пропуск подтверждения:**
- При воспроизведении все действия применяются автоматически.
- Скорость воспроизведения можно уменьшить, чтобы проверять шаги.

**Сохранение истории:**
- Храните старые файлы действий.
- Сравнивайте разные подходы к настройке.
- Используйте прошлые сеансы для обучения.

## Тест задержки AFR

Автоматическое измерение транспортной задержки выхлопной системы — времени, которое проходит между изменением подачи топлива и появлением соответствующего изменения на широкополосном датчике. AutoTune требуется это значение (параметр «lambda delay»), чтобы сопоставлять измеренный AFR с количеством топлива, фактически впрыснутым в соответствующий момент. Если задать слишком малую задержку, рекомендации могут начать колебаться.

### Обзор

Тест выполняет следующие действия:
1. На заданное время изменяет на один байт содержимое оперативной памяти калибровки — параметр прогревочного обогащения на участке прогретого двигателя — в сторону **обогащения** на заданную величину.
2. Записывает график AFR во время изменения и после возврата исходного значения.
3. Определяет время от момента изменения до достижения **половины установившегося отклонения** (медианное время прохождения, то есть транспортную задержку), а не шумный начальный фронт.
4. Повторяет измерение и накапливает результаты в карте задержки **RPM × нагрузка**.

### Открытие теста задержки AFR

1. Подключитесь к ЭБУ и откройте проект.
2. Перейдите в **Tools → AFR Delay Test…**.

### Настройки

| Параметр | Диапазон | Значение |
|---|---|---|
| Step size | 3–20% | Насколько сильнее обогащается смесь при тестовом изменении |
| Hold | 500–5000 мс | Время удержания изменения до возврата исходного значения |
| Settle | 500–10000 мс | Окно восстановления, записываемое после возврата параметра |
| Repeats | 1–200 шагов | Фиксированное количество шагов для одной рабочей точки |
| Run until stopped | — | Непрерывный режим: продолжайте движение, пока карта заполняется |

По одному шагу нельзя точно определить задержку: разброс между измерениями больше самого отклика. Результат становится информативным только после наложения нескольких графиков. На графике отображается каждый шаг, поэтому разброс можно оценить визуально.

### Карта задержки

Каждый успешный шаг попадает в ячейку таблицы RPM × нагрузка (средняя задержка и число измерений для каждой ячейки). Наиболее полезен режим **Run until stopped**: запустите его перед поездкой, и каждая устойчивая рабочая точка, через которую проходит двигатель, добавит измерение. Так карта заполняется в тех режимах, в которых автомобиль действительно эксплуатируется.

### Безопасность

- Тест может только **обогатить** смесь, но никогда не обедняет её.
- Изменения записываются только в **оперативную память** — ничего не прожигается в ЭБУ; после выключения и повторного включения зажигания восстанавливается сохранённая калибровка.
- Изменяемый параметр WUE восстанавливается после каждого шага и при нажатии Stop.
- Тест не управляет дросселем — поддерживайте стабильный режим двигателя самостоятельно.

### Интерпретация результатов

- Причины статуса **«No measurement»** показываются для каждого шага: нестабильный исходный режим (вы изменили положение дросселя), отсутствие отклика (шаг слишком мал относительно шума) или отсутствие стабилизации отклика за время удержания. Если проблема в последнем, диалог предложит увеличить Hold.
- Когда карта получит достаточный охват, выберите репрезентативное значение и укажите его как фиксированную задержку lambda в AutoTune (см. [Настройка AutoTune](./autotune/setup.md#компенсация-задержки-lambda)). Кривая задержки по RPM по умолчанию достигает примерно 200 мс — это значительно меньше реального времени прохождения выхлопных газов, которое часто составляет 400–1000 мс.

## Сброс к значениям по умолчанию

Быстрый сброс калибровки к заводским значениям для начала настройки с чистого листа.

### Обзор

Инструмент позволяет сбросить:
- **Текущую таблицу:** одну таблицу к значениям по умолчанию из INI.
- **Всю калибровку:** все константы к значениям по умолчанию из INI.

### Когда использовать

- **Начать заново:** калибровка испорчена и требуется сброс.
- **Эталонная база:** сравнение текущей калибровки с заводской.
- **Тестирование:** изоляция изменений конкретной таблицы.
- **Аварийный вариант:** возврат к исходной конфигурации в крайнем случае.

### Порядок работы

1. Перейдите в **Tools → Reset to Defaults**.
2. Выберите область сброса:
   - только текущая таблица;
   - все таблицы.
3. Подтвердите сброс.
4. Готово — изменения вступают в силу немедленно.

### Предупреждение

**Это действие нельзя отменить!**
- Перед сбросом убедитесь, что калибровка сохранена.
- Перед сбросом создайте резервную копию.
- Изменения применяются сразу.

### После сброса

После выполнения операции калибровка:
- содержит исходные значения из INI;
- теряет все изменения, сделанные после загрузки;
- готова к новой настройке;
- может быть сохранена как новый файл.

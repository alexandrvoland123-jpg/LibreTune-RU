# Математические каналы и механизм вычисления выражений

В LibreTune встроен мощный механизм вычисления выражений во время работы программы. Он используется для **математических каналов** (`OutputChannels`) и позволяет описывать в файле конфигурации ЭБУ (INI) вычисляемые значения на основе исходных данных датчиков.

## Обзор

Математические каналы задаются в разделе `[OutputChannels]` файла INI. В отличие от обычных каналов, которые непосредственно считывают байты из памяти ЭБУ, математические каналы вычисляются на компьютере.

**Основные возможности:**
- **Арифметика:** сложение, вычитание, умножение, деление и остаток от деления.
- **Побитовые операции:** AND (`&`), OR (`|`), XOR (`^`), сдвиг влево (`<<`) и вправо (`>>`).
- **Сравнения:** больше (`>`), меньше (`<`), равно (`==`), не равно (`!=`) и другие.
- **Логические операторы:** AND (`&&`), OR (`||`), NOT (`!`).
- **Тернарный оператор:** условное выражение (`condition ? true_val : false_val`).
- **Функции:** встроенная библиотека математических и вспомогательных функций.

## Синтаксис выражений

Выражения записываются в стандартной инфиксной форме. Имена переменных ссылаются на другие выходные каналы или константы.

### Примеры
```ini
; Простая арифметика
dutyCycle = { (pw * rpm) / 1200 }

; Условная логика (тернарный оператор)
engineState = { rpm > 500 ? (tps > 80 ? 3 : 1) : 0 }

; Побитовые операции
fanStatus = { (outputs & 4) != 0 }

; Вызов функции
smoothedAfr = { round(afr) }
```

## Встроенные функции

### Математические функции
| Функция | Описание | Пример |
|---|---|---|
| `min(a, b)` | Возвращает меньшее значение | `min(clt, 100)` |
| `max(a, b)` | Возвращает большее значение | `max(tps, 0)` |
| `abs(x)` | Возвращает абсолютное значение | `abs(map - baro)` |
| `round(x)` | Округляет до ближайшего целого | `round(lambda * 100)` |
| `sqrt(x)` | Квадратный корень | `sqrt(x_sq)` |
| `log(x)` | Натуральный логарифм | `log(pressure)` |
| `exp(x)` | Экспонента (e^x) | `exp(factor)` |
| `sin(x)`, `cos(x)`, `tan(x)` | Тригонометрические функции (углы в радианах) | `sin(angle)` |

### Системные и вспомогательные функции
| Функция | Описание | Пример |
|---|---|---|
| `timeNow()` | Текущее системное время в миллисекундах | `timeNow() / 1000` |
| `isOnline()` | Возвращает 1 при подключении и 0 в противном случае | `isOnline()` |
| `isNaN(x)` | Возвращает 1, если значение равно NaN | `isNaN(sensor)` |

### Условная функция (для совместимости)
| Функция | Описание | Пример |
|---|---|---|
| `if(cond, true, false)` | Аналог тернарного оператора | `if(rpm>0, 1, 0)` |

## Порядок вычисления

**Вычислитель** автоматически определяет правильную последовательность операций. Вручную располагать каналы в определённом порядке в INI не требуется.

1. **Обычные каналы** считываются из блока памяти ЭБУ.
2. **Математические каналы** вычисляются несколькими проходами:
   - **Проход 1:** каналы, зависящие только от исходных значений.
   - **Проход 2:** каналы, зависящие от результатов первого прохода.
   - **Проход 3:** каналы с более глубокой цепочкой зависимостей.

Циклические зависимости (например, `A = B + 1` и `B = A + 1`) приведут к значению `NaN` (не число) либо к резервному значению 0.

## Производительность

Выражения разбираются один раз при загрузке определения ЭБУ и затем кэшируются. Вычисления во время работы оптимизированы и позволяют обрабатывать сотни каналов с частотой 100 Гц и выше без существенной нагрузки на процессор.

# Сценарии Lua

LibreTune включает изолированную среду выполнения Lua для простой автоматизации. Используйте консоль Lua для быстрых вычислений, пользовательских вспомогательных функций и будущих сценариев действий.

## Консоль Lua

Откройте **Инструменты → Консоль Lua**, чтобы выполнить сценарий. В консоли отображаются результаты вызова `print()` и возвращаемое сценарием значение.

Пример:

- `print('Hello from Lua')`
- `return 2 + 2`

В области вывода появится:

- `Hello from Lua`
- `=> 4`

## Ограничения изолированной среды

Среда выполнения Lua работает в изоляции:

- **Нет доступа к файловой системе**
- **Нет доступа к сети**
- **Нет выполнения команд операционной системы**

Это делает сценарии безопасными и предсказуемыми при настройке двигателя.

## Рекомендации

- Используйте Lua для простых математических операций и логики.
- Пишите короткие сценарии, решающие конкретную задачу.
- Для изменения калибровок отдавайте предпочтение редактору таблиц и встроенным инструментам.

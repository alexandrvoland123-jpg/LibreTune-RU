# Консоль ЭБУ

Консоль ЭБУ предоставляет текстовый интерфейс команд для обмена данными с блоками управления двигателем rusEFI, FOME и epicEFI.

## Обзор

Консоль позволяет отправлять текстовые команды непосредственно в ЭБУ и получать ответы в реальном времени. Это полезно для диагностики, настройки, отладки прошивки и доступа к функциям, которые не представлены в стандартном интерфейсе настройки.

> **Примечание:** консоль ЭБУ доступна только для блоков на базе rusEFI (rusEFI, FOME, epicEFI). ЭБУ Speeduino и MegaSquirt не поддерживают текстовый интерфейс консоли.

## Открытие консоли

1. Подключитесь к ЭБУ rusEFI, FOME или epicEFI.
2. Откройте **Инструменты → Консоль ЭБУ**.
3. Откроется новая вкладка с интерфейсом консоли.

Пункт меню доступен только при выполнении всех условий:
- открыт проект;
- установлено соединение с ЭБУ;
- тип ЭБУ поддерживает команды консоли (rusEFI/FOME/epicEFI).

## Использование консоли

### Отправка команд

1. Введите команду в поле ввода в нижней части окна.
2. Нажмите **Enter**, чтобы отправить её.
3. Команда и ответ появятся в журнале вывода.

### Цвета сообщений

Цвета помогают различать типы сообщений:

| Цвет | Префикс | Значение |
|---|---|---|
| **Голубой** | `>` | Отправленная вами команда |
| **Серый** | `<-` | Ответ ЭБУ |
| **Красный** | `✗` | Сообщение об ошибке |
| **Оранжевый** | `…` | Ожидание ответа |

### История команд

Перемещайтесь по ранее отправленным командам:
- **Стрелка вверх**: предыдущая команда.
- **Стрелка вниз**: следующая команда.

### Очистка консоли

Нажмите кнопку **Очистить** в заголовке консоли, чтобы удалить историю вывода с экрана.

## Быстрый обмен FOME

Если на ЭБУ установлена прошивка **FOME**, LibreTune может использовать оптимизированный протокол обмена для команд консоли. Он включён по умолчанию и обеспечивает более быструю передачу команд и ответов.

- Переключатель появляется автоматически при обнаружении ЭБУ FOME.
- Если ускоренный режим по какой-либо причине не работает, LibreTune незаметно переключается на стандартный протокол.
- При возникновении проблем ускоренный режим можно отключить в заголовке консоли.

Этот параметр также доступен в **Настройки → Быстрый обмен FOME**.

## Состояния подключения

| Состояние | Поведение |
|---|---|
| **Подключено** | Команды можно отправлять, ответы принимаются. |
| **Отключено** | Поле ввода недоступно; отображается сообщение «Нет подключения». |
| **Загрузка** | Мигающий курсор показывает, что ЭБУ обрабатывает команду. |

## Типичные задачи

- **Версия прошивки**: запрос информации о сборке прошивки ЭБУ.
- **Диагностика датчиков**: чтение исходных значений датчиков для поиска неисправностей.
- **Команды настройки**: изменение параметров, недоступных в графическом интерфейсе.
- **Отладка**: наблюдение за внутренним состоянием ЭБУ во время разработки.

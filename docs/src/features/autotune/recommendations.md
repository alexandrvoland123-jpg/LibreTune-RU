# Как понимать рекомендации AutoTune

В этом разделе описано, как AutoTune рассчитывает рекомендуемые корректировки.

## Основной алгоритм

AutoTune сравнивает фактическое AFR с целевым AFR и рассчитывает корректировку:

```text
Ошибка = (Фактическое AFR - Целевое AFR) / Целевое AFR
Коррекция = Текущее VE × (1 - Ошибка)
```

### Пример
- Целевое AFR: 14.7.
- Фактическое AFR: 15.5 (бедная смесь).
- Ошибка: (15.5 - 14.7) / 14.7 = 5.4%.
- Если VE равно 75, рекомендация: 75 × 1.054 = 79.1.

## Взвешенное усреднение

AutoTune не использует отдельные показания. Программа накапливает данные:

1. **Количество попаданий**: число отсчётов, полученных в данной ячейке.
2. **Взвешенное среднее**: более свежие отсчёты имеют больший вес.
3. **Достоверность**: чем больше попаданий, тем выше достоверность результата.

Отображаемая рекомендация представляет собой взвешенное среднее всех накопленных отсчётов.

## Цветовая индикация

### Сетка рекомендаций
- **Синий**: увеличить подачу топлива (смесь бедная).
- **Красный**: уменьшить подачу топлива (смесь богатая).
- **Серый**: данных нет или количество попаданий недостаточно.

### Интенсивность цвета
- **Яркий**: требуется большая корректировка.
- **Бледный**: требуется небольшая корректировка.
- **Нейтральный**: целевое значение достигнуто.

## Тепловые карты

### Карта веса ячеек
Показывает охват данными:
- **Яркие ячейки**: много отсчётов, высокая достоверность.
- **Бледные ячейки**: мало отсчётов, низкая достоверность.
- **Тёмные ячейки**: данные отсутствуют.

### Карта изменений ячеек
Показывает величину корректировки:
- **Яркие ячейки**: рекомендуется большое изменение.
- **Бледные ячейки**: рекомендуется небольшое изменение.

## Количество попаданий

Минимальное количество попаданий, необходимое для доверия рекомендации:
- **1–5**: предварительные данные (серый цвет).
- **5–20**: данные накапливаются (светлый цвет).
- **Более 20**: результату можно доверять в большей степени (насыщенный цвет).

Минимальный порог попаданий настраивается в параметрах.

## Влияние фильтров

Отсчёты отклоняются, если:
- RPM выходит за установленный диапазон;
- температура охлаждающей жидкости слишком низкая;
- TPS меняется слишком быстро;
- активно ускорительное обогащение.

Отфильтрованные отсчёты не участвуют в расчёте рекомендаций.

## Ограничение коррекций

Рекомендации ограничиваются заданными пределами:

```text
Итог = clamp(Рекомендация,
             Текущее значение - MaxDecrease,
             Текущее значение + MaxIncrease)
```

Если рекомендация превышает допустимые пределы, рядом с ячейкой появляется предупреждающий значок.

## Интерпретация результатов

### Все ячейки показывают бедную или богатую смесь

Если все ячейки указывают в одну сторону, возможны следующие причины:
- проблема с давлением топлива;
- ошибка калибровки датчика;
- необходимость общей корректировки.

### Отдельные области таблицы

Локальные корректировки могут указывать на:
- обычные различия наполнения цилиндров и поведения VE;
- необходимость точной настройки отдельных областей таблицы.

### Нестабильные рекомендации

Случайные изменения могут быть вызваны:
- шумом датчика;
- нестабильной работой двигателя;
- некорректными данными (проверьте фильтры).

## Когда применять рекомендации

Применяйте рекомендации, если:
- охвачена значительная часть таблицы;
- показания в каждой ячейке стабильны;
- тепловая карта показывает достаточное количество попаданий;
- отсутствуют предупреждающие индикаторы.

Подождите накопления данных, если:
- охват таблицы недостаточен;
- рекомендации постоянно меняются;
- ограничения коррекции срабатывают слишком часто.

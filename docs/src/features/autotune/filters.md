# Фильтры и ограничения коррекции

Управление качеством данных и ограничение величины корректировок.

## Зачем нужны фильтры

Не каждое показание AFR отражает установившийся режим работы двигателя:
- **Разгон**: обогащение смеси искажает показания.
- **Торможение двигателем**: отключение подачи топлива смещает показания в бедную сторону.
- **Холодный двигатель**: требования к составу смеси отличаются.
- **Запаздывание датчика**: широкополосный датчик кислорода реагирует не мгновенно.

Фильтры позволяют учитывать в рекомендациях только пригодные данные.

## Типы фильтров

### Фильтр оборотов (RPM)
**Назначение**: ограничить диапазон рабочих оборотов.

| Параметр | Описание | По умолчанию |
|---|---|---|
| Min RPM | Не учитывать данные ниже этого значения | 800 |
| Max RPM | Не учитывать данные выше этого значения | 6500 |

**Когда менять настройки**:
- увеличьте минимум, если холостой ход нестабилен;
- уменьшите максимум, если двигатель не работает на таких высоких оборотах.

### Фильтр температуры охлаждающей жидкости
**Назначение**: исключить данные холодного двигателя.

| Параметр | Описание | По умолчанию |
|---|---|---|
| Min CLT | Не учитывать данные ниже этого значения | 160°F |

**Когда менять настройки**:
- уменьшите порог для испытаний в холодном климате;
- увеличьте его, если двигателю требуется больше времени для прогрева.

### Фильтры положения дроссельной заслонки
**Назначение**: исключить переходные режимы.

| Параметр | Описание | По умолчанию |
|---|---|---|
| Min TPS | Не учитывать данные при закрытой заслонке | 1% |
| Max TPS Rate | Не учитывать слишком быстрые изменения | 10%/с |

**Когда менять настройки**:
- увеличьте Min TPS, если мешают помехи при торможении двигателем;
- уменьшите Max TPS Rate, если хотите получать больше данных (то есть ослабить фильтрацию).

### Фильтр обогащения при разгоне
**Назначение**: исключить периоды работы ускорительного обогащения.

| Параметр | Описание | По умолчанию |
|---|---|---|
| Exclude AE | Исключать данные при активном AE | Да |

Большинство ЭБУ сообщает, когда активно ускорительное обогащение. Этот фильтр исключает такие данные.

## Ограничения величины коррекции

### Зачем ограничивать коррекцию

Большие корректировки могут быть опасны:
- **Слишком богатая смесь**: смывание масляной плёнки со стенок цилиндров, образование нагара.
- **Слишком бедная смесь**: детонация и прогар поршней.
- **Неверное направление коррекции**: накопление и усиление ошибки.

Ограничения предотвращают неконтролируемое изменение калибровки.

### Ограничения на одно обновление

| Параметр | Описание | По умолчанию |
|---|---|---|
| Max Increase | Максимальное увеличение подачи топлива за одно обновление | 10% |
| Max Decrease | Максимальное уменьшение подачи топлива за одно обновление | 10% |

При каждом применении изменений ячейка может измениться не более чем на указанную величину.

### Абсолютные ограничения

| Параметр | Описание | По умолчанию |
|---|---|---|
| Absolute Max | Максимальное суммарное отклонение от исходного значения | 25% |

Даже после нескольких обновлений значение ячейки не сможет отклониться от исходного больше указанного предела.

### Поэтапная стратегия

Начинайте с консервативных значений и увеличивайте ограничения по мере уточнения калибровки:

| Этап | На одно обновление | Абсолютный предел | Когда применять |
|---|---:|---:|---|
| Начальный | 5% | 15% | Базовая калибровка ещё грубая |
| Уточнение | 10% | 25% | Настройка близка к цели |
| Точная настройка | 15% | 30% | Остались небольшие отклонения |

## Индикаторы фильтров

### Строка состояния

Показывает текущий результат фильтрации:
- **Данные приняты**: данные прошли фильтры.
- **Данные отфильтрованы**: данные отклонены; отображается причина.

### Предупреждения ячеек
- **Достигнут предел коррекции**: рекомендация превышает допустимую величину.
- **Ячейка заблокирована**: ячейка вручную исключена из обновлений.

## Устранение проблем с фильтрами

### «Все данные отфильтрованы»
1. Проверьте CLT — возможно, двигатель ещё холодный.
2. Проверьте диапазон RPM — возможно, он слишком узкий.
3. Проверьте ограничение скорости изменения TPS — возможно, оно слишком строгое.

### «Недостаточно попаданий»
1. Ослабьте фильтры, чтобы принимать больше данных.
2. Дольше работайте в нужных режимах.
3. Удерживайте двигатель в каждой ячейке дольше.

### «Непостоянные рекомендации»
1. Ужесточите фильтр скорости изменения TPS.
2. Включите исключение данных ускорительного обогащения.
3. Проверьте датчики.

# Руководство по использованию AutoTune

Пошаговое руководство по настройке таблицы VE с помощью AutoTune в реальных условиях эксплуатации.

## Быстрый запуск (5 минут)

1. **Подключитесь** к ЭБУ
2. **Откройте** Tools → AutoTune (или Ctrl+Shift+A)
3. **Выберите** таблицу VE
4. **Нажмите** Start (с настройками по умолчанию)
5. **Поездите** в обычном режиме 5–10 минут
6. **Проверьте** охват данных на тепловой карте
7. **Нажмите** Send to ECU, чтобы применить изменения

## Перед началом работы

### Контрольный список требований
- [ ] Установлен широкополосный датчик O2, на него подано питание
- [ ] Сигнальный провод AFR подключён к ЭБУ
- [ ] Двигатель прогрет до рабочей температуры (температура ОЖ выше 180°F)
- [ ] Текущая калибровка работает без ошибок
- [ ] Нет индикатора Check Engine, указывающего на серьёзные неисправности
- [ ] По возможности выберите хорошую погоду и контролируемые условия

### Меры безопасности
- **Не выполняйте настройку в одиночку** — возьмите помощника-наблюдателя.
- **Используйте знакомые дороги** — избегайте новых и сложных маршрутов.
- **Не выезжайте на скоростные трассы** — используйте малозагруженные улицы или закрытую площадку.
- **Держите телефон под рукой** на случай чрезвычайной ситуации.
- **Будьте готовы отключить систему** — при необходимости выньте предохранитель или отключите зажигание.

## Порядок проведения сеанса

### Этап 1. Первоначальная настройка (5 минут)

**Шаг 1. Откройте AutoTune**
```
Tools → AutoTune
Или с клавиатуры: Ctrl+Shift+A
```

**Шаг 2. Выберите таблицу**
- По умолчанию: VE Table 1 (наиболее распространённый вариант).
- Предлагаются только топливные таблицы (VE): AutoTune корректирует количество топлива, поэтому таблицы зажигания, целевого AFR и другие типы намеренно недоступны для выбора.
- В конфигурациях с двумя топливными алгоритмами (например, второй топливный алгоритм Speeduino) рядом с VE Table 1 отображается **VE Table 2**.
- Secondary: установите флажок, чтобы одновременно настраивать вторую таблицу VE. Если в калибровке только одна топливная таблица, селектор покажет «No other fuel tables».

**Шаг 3. Настройте основные параметры**
```
Целевой AFR: 14.7 (стехиометрия бензина)
          14.0 (E85)
          13.0 (высокий наддув, богатая смесь)
Алгоритм: Simple (рекомендуется начинающим)
```

**Источник нагрузки (MAP, MAF или TPS)**
- **MAP (Speed Density):** используется по умолчанию для таблиц VE.
- **MAF:** используется для таблиц, основанных на массовом расходе воздуха.
- **TPS (Alpha-N / ITB):** используется, если ось нагрузки таблицы VE соответствует положению дросселя — конфигурации с индивидуальными дросселями (ITB) / Alpha-N.
- Если ось нагрузки таблицы указывает канал дросселя, AutoTune автоматически переключается на **TPS**; если указан MAF — на **MAF**.
- В Speeduino канал оси нагрузки называется `fuelLoad` независимо от топливного алгоритма, поэтому AutoTune также считывает константу **Control Algorithm** (Engine Constants → Injection Setup): значение `TPS` автоматически выбирает источник нагрузки по дросселю. Изменение этой константы на `MAP`/`TPS` также немедленно меняет масштаб оси нагрузки (0–100% в режиме Alpha-N).
- Если канал MAF не обнаружен, AutoTune возвращается к **MAP** и показывает подсказку.
- Выбор источника нагрузки не меняет отображаемые значения оси — узлы всегда берутся из вашей калибровки. Он определяет только то, какой текущий канал используется для отнесения данных к ячейкам.

**Шаг 4. Установите пределы влияния**
Для ПЕРВОГО сеанса с этой калибровкой используйте:
```
Максимальное увеличение:   5%
Максимальное уменьшение:   5%
Абсолютный максимум:  15%
```

Это консервативные значения. Позже их можно увеличить.

**Шаг 5. Проверьте фильтры**
Настройки фильтров по умолчанию подходят для большинства случаев. Меняйте их только при необходимости:
- Если двигатель нестабильно работает на холостом ходу: увеличьте Min RPM до 1200.
- При настройке дизельного двигателя: существенно скорректируйте температурные фильтры.
- При испытаниях на трассе: уменьшите Min TPS до 0 для проверки при движении накатом.
- Для ITB / Alpha-N значение Max TPS Rate по умолчанию (50 %/s) уже учитывает быстрое перемещение отдельных дросселей; реальные переходные процессы ускорения по-прежнему исключаются отдельным фильтром.

**Во время работы — индикатор выборок**

Во время сеанса небольшой индикатор под строкой заголовка показывает, сколько выборок прошло фильтры и какой фильтр отбрасывает данные (сначала отображается самая частая причина; наведите курсор, чтобы увидеть полную статистику). **Если кажется, что AutoTune ничего не делает, сначала проверьте этот индикатор:** `0 samples accepted` при растущем числе отклонений означает, что фильтры (обычно Min CLT во время прогрева или Max TPS Rate) отбрасывают все данные.

**Шаг 6. Нажмите Start**
- AutoTune начинает получать данные широкополосного датчика.
- Статус меняется на «Running».
- В интерфейсе отображается «Waiting for data…».

### Этап 2. Движение и сбор данных (10–30 минут)

**Где проводить испытания**
- На знакомых местных дорогах.
- При небольшом трафике и предсказуемых условиях.
- Сочетайте движение с постоянной скоростью и плавные ускорения.
- Не ездите агрессивно и не делайте резких изменений режима.

**Режим движения 1. Настройка крейсерского режима (подходит для города)**
```
1. Drive at 30 mph, constant throttle for 30 seconds
2. Accelerate gently to 40 mph, hold for 30 seconds
3. Cruise at 50 mph for 1 minute
4. Repeat with different throttle positions
5. Vary RPM: 2000, 2500, 3000, 3500 RPM
```

**Режим движения 2. Настройка на шоссе (подходит для длинных прямых участков)**
```
1. Cruise at 60 mph, light throttle, for 2 minutes
2. Slight acceleration to 65 mph, cruise 1 minute
3. Return to 60 mph
4. Repeat with different engine loads
```

**Режим движения 3. Смешанный (наиболее приближён к реальности)**
- Двигайтесь в обычном режиме.
- Включите в маршрут городские и загородные участки.
- Естественным образом меняйте скорость и нагрузку.
- Продолжительность поездки — не менее 20 минут.

**Чего следует избегать**
- ❌ Резкого ускорения (срабатывает фильтр ускорительного обогащения).
- ❌ Движения накатом с отсечкой топлива (срабатывает фильтр замедления).
- ❌ Резких коротких нажатий на дроссель (срабатывает фильтр скорости изменения).
- ❌ Работы на холодном двигателе (данные отклоняет фильтр Min CLT).
- ❌ Настройки холостого хода (фильтр Min TPS игнорирует эти данные).

**Контроль во время движения**
- Если есть второй экран, наблюдайте за тепловой картой на нём.
- Следите за охватом данных в обычном рабочем диапазоне.
- Не смотрите постоянно на экран — безопасность важнее!

**Отображение линии траектории**

Сетка отображает поверх ячеек **линию траектории** — такой же индикатор пути, как в редакторах топливных таблиц: линия проходит через недавно посещённые ячейки, точки постепенно исчезают, а ячейка, в которой двигатель находится *прямо сейчас*, подсвечивается ореолом.

- Линия появляется при поступлении данных реального времени (запуск сеанса не требуется).
- Включайте и выключайте её кнопкой **MapPin** на панели инструментов сетки.
- Цвет и время затухания задаются в Settings → настройках курсора/траектории.

**Направление оси Y**

Кнопка **↑↓** рядом с выбором тепловой карты меняет направление оси Y: ноль сверху или ноль снизу. Это та же глобальная настройка, что используется редакторами таблиц. Изменяется только отображение; данные ячеек, блокировки и рекомендации не затрагиваются.

---

### Этап 3. Проверка данных (5 минут)

**Проверьте охват тепловой карты**
```
Вид Heat Map: Cell Weighting (показывает охват данными).
```

- 🟢 Яркие ячейки: хороший охват, высокая достоверность.
- 🟡 Ячейки средней яркости: достаточный охват, данные можно использовать.
- 🔴 Тёмные ячейки: данных мало или нет.

**Области, которые следует охватить**
- **Idle**: 800-1000 RPM, 0-5% TPS
- **Cruise**: 2000-3500 RPM, 10-30% TPS
- **Highway**: 3000-4000 RPM, 20-40% TPS
- **Acceleration**: 2000-5000 RPM, 50-100% TPS (if possible)

**Проверка качества**
```
Переключитесь на Cell Change (показывает величину коррекции).
```

- Однородный цвет — корректировки согласованы.
- Резко различающиеся цвета — несогласованные данные или проблемы с датчиками.
- Всё синее — смесь бедная.
- Всё красное — смесь богатая.
- Разные цвета — собраны данные в разных условиях.

---

### Этап 4. Применение изменений (3 минуты)

**Проверьте рекомендации**
```
1. Вернитесь к просмотру основной таблицы.
2. Посмотрите рекомендуемые значения (светло-синее/красное наложение).
3. Проверьте, нет ли подозрительных чрезмерных значений.
4. Проверьте заблокированные ячейки (если они есть).
```

**Send to ECU**
```
Кнопка: Send to ECU (применяет изменения без сохранения файла).
```

Изменения отправляются в оперативную память ЭБУ и вступают в силу немедленно.

**Проверочная поездка (5 минут)**
- Совершите короткую поездку (например, вокруг квартала).
- Оцените реакцию на педаль газа — стала ли она лучше?
- Прислушайтесь, нет ли звона/детонации или провалов.
- Если возможно, наблюдайте за широкополосным датчиком — AFR должен быть ближе к целевому.

**Если результат хороший: сохраните калибровку**
```
File → Save Tune (Ctrl+S)
```

**Если результат пока не устраивает: продолжите настройку**
```
Click: Start again (with same or adjusted authority limits)
```

### Этап 5. Итерационное уточнение

**Результаты первого сеанса**
- Обычно предварительные (отклонение AFR 5–10%).
- Дают основу для дальнейшей настройки.
- Не ожидайте идеального результата сразу.

**Второй сеанс (на следующий день)**
```
1. Немного увеличьте пределы влияния:
   Максимальное увеличение:  10%
   Максимальное уменьшение:  10%
   Абсолютный максимум:  30%

2. Повторно настройте те же области (30 минут).
3. Отправьте изменения в ЭБУ и проверьте улучшение.
4. Сохраните калибровку.
```

**Постепенная стратегия**
| Сеанс | Степень влияния | Цель | Комментарии |
|---------|-----------|------|----------|
| 1 | Консервативная (5%) | Получить базовый охват | Медленные, безопасные корректировки |
| 2 | Умеренная (10%) | Заполнить пробелы, уточнить настройки | Проверить стабильность |
| 3 | Повышенная (15%) | Финальная доводка | Большинство ячеек сошлись |
| 4 и далее | Точная настройка (5–10%) | Оптимизировать отдельные области | Небольшие корректировки |

## Расширенные методы

### Настройка нескольких таблиц

В конфигурациях с двумя топливными таблицами можно настроить обе VE-таблицы за один сеанс:

```
1. Tick "Secondary:"
2. Primary: VE Table 1
3. Secondary: VE Table 2

Двигайтесь в обычном режиме — обе таблицы независимо собирают попадания и рекомендации.
```

Таблица целевого AFR здесь **не настраивается** — она служит эталоном, относительно которого AutoTune выполняет измерения, и выбирается при предварительной проверке. Угол зажигания настраивается отдельно, вручную: масштабирование градусов опережения по ошибке AFR могло бы увеличить опережение именно в бедных ячейках с высокой нагрузкой, где существует риск детонации. Поэтому AutoTune полностью исключает таблицы зажигания.

**Переключение таблиц во время сеанса**

Селекторы Primary, Secondary и Load Source остаются активными во время сеанса — останавливать и запускать его заново не требуется:

```
1. Change Primary or Secondary (or tick/untick the secondary box)
2. Сеанс перенастраивается на месте; накопленные рекомендации сохраняются для таблиц, у которых не изменились сама таблица и узлы осей.
3. Если из сеанса удаляется таблица с ещё не отправленными рекомендациями, программа сначала предлагает выбрать: Send & Switch / Discard & Switch / Cancel.
```

Явный цикл **Stop → Start** по-прежнему очищает накопленные рекомендации обеих таблиц, как и раньше.

### Блокировка ячеек

Заблокируйте ячейки, которые требуется защитить от изменений.

**Перед настройкой**
```
1. Щёлкните правой кнопкой по ячейке сетки.
2. Выберите «Lock Selected Cells».
3. Заблокированные ячейки отмечаются значком 🔒.
4. AutoTune будет пропускать их.
```

**Когда это полезно**
- Блокируйте ячейки холостого хода, если они уже настроены.
- Блокируйте ячейки высокого наддува, чтобы избежать чрезмерной коррекции.
- Блокируйте ячейки с сомнительным качеством данных.

### Масштабирование и навигация

Работа с отдельными областями:

```
1. Увеличьте область низких оборотов и малой нагрузки.
2. Тщательно настраивайте её в течение 10 минут.
3. Перейдите к другой области.
4. Повторите для каждой области.
```

### Экспорт CSV

Сохраните рекомендации для последующего анализа:

```
File → Export AutoTune Data
Откроется диалог сохранения.
Изучите файл в табличном редакторе.
Сравните значения до и после.
```

## Устранение неполадок

### «No Data» / серая тепловая карта

**Возможные причины**
- Двигатель не работает.
- Широкополосный датчик неисправен.
- Сигнал AFR не подключён к ЭБУ.
- Фильтры настроены слишком жёстко.

**Решение**
```
1. Убедитесь, что широкополосный датчик включается.
2. Проверьте светодиод датчика — он должен мигать.
3. Проверьте вход AFR на диагностическом экране ЭБУ.
4. Ослабьте фильтры: уменьшите Min RPM и Min TPS.
5. Убедитесь, что ЭБУ получает данные канала AFR.
```

**Сначала проверьте индикатор выборок.** Во время работы индикатор под строкой заголовка (например, `132 samples accepted · 400× clt below min_clt · …`; наведите курсор для полной статистики) точно показывает, какой фильтр отбрасывает данные:

| Причина отклонения | Значение | Решение |
|---|---|---|
| `clt below min_clt` | Двигатель ещё прогревается | Дождитесь рабочей температуры или уменьшите Min CLT |
| `tps_rate above max_tps_rate` | Дроссель перемещается слишком быстро | Увеличьте Max TPS Rate (для ITB требуется 50+ %/s) |
| `rpm out of range` | RPM за пределами диапазона | Измените границы фильтра RPM |
| `afr at sensor rail` | Широкополосный датчик достиг предела (< 10.0 или > 19.5) | Проверьте датчик и проводку: при отсечке топлива или неисправности датчик может показывать предельно бедную смесь |
| `overrun fuel cut` | Активна отсечка топлива при замедлении | Это нормально — такие данные намеренно не включаются в таблицу |
| `accel enrichment active` | Активно ускорительное обогащение | Это нормально — данные переходного процесса не являются данными VE |

Если индикатор показывает принятые выборки, но тепловая карта остаётся пустой, двигатель ещё не проходил через соответствующие ячейки — продолжайте движение.

### Все ячейки синие (очень бедная смесь)

**Это опасно — не игнорируйте проблему!**

**Причины**
- Слишком низкое давление топлива.
- Неисправен топливный насос.
- Проблема с форсунками.
- Неправильная калибровка датчика.

**Решение**
```
1. НЕМЕДЛЕННО остановите AutoTune.
2. Проверьте манометр давления топлива (должно быть 43–45 PSI).
3. Проверьте работу топливного насоса.
4. Проверьте соединения форсунок.
5. До устранения неисправности НЕ ездите с высокой нагрузкой.
```

### Все ячейки красные (очень богатая смесь)

**Менее опасно, чем бедная смесь**, но это всё равно неисправность.

**Причины**
- Слишком высокое давление топлива.
- Регулятор заклинил в открытом положении.
- Датчик откалиброван с завышением.
- Неправильно задано общее масштабирование топлива.

**Решение**
```
1. Проверьте давление топлива (возможно, оно превышает 50 PSI).
2. Проверьте нулевую точку датчика.
3. При наличии настройки уменьшите общую топливную коррекцию.
4. Продолжите настройку — значения будут сходиться.
```

### На тепловой карте есть пробелы

**Это нормально** — невозможно охватить каждую ячейку.

**Решение**
```
1. Определите, в каких ячейках отсутствуют данные.
2. Спланируйте режим движения, чтобы попасть в эти ячейки.
3. На следующем сеансе сосредоточьтесь на этих областях.
4. Некоторые ячейки можно оставить без изменений.
```

### Показания широкополосного датчика колеблются

**Это нормальное явление** — датчики могут выдавать шумные показания.

**Почему AutoTune справляется с этим**
- Взвешенное усреднение фильтрует шум.
- Накапливается большое количество выборок.
- Фильтрация уже встроена в алгоритм.

**Если колебания слишком сильные**
- Проверьте проводку датчика (нет ли ослабленных соединений?).
- Проверьте электромагнитные помехи (не проложены ли провода свечей рядом с проводом датчика?).
- Возможно, датчик неисправен.

### Коррекции не соответствуют фактическому AFR

**Причина:** компенсация задержки Lambda или запаздывание датчика.

**Пояснение**
- Выхлопным газам требуется 50–200 мс, чтобы достичь датчика.
- AutoTune сопоставляет AFR с ячейкой VE, соответствовавшей режиму в тот момент.
- Небольшое несовпадение нормально.

**Решение**
- Доверяйте алгоритму — он предназначен именно для такой компенсации.
- Чем больше выборок данных, тем точнее сопоставление.
- Второй сеанс настройки часто улучшает результат.

## Примеры из практики

### Сценарий 1. Атмосферный бензиновый двигатель

**Цель:** настроить таблицу VE для плавного движения с постоянной скоростью.

```
Целевой AFR:     14.7
Сеанс 1:      5% authority, 20 minutes cruise
Result:         Heat map shows green cruising range
Отправить изменения:   Yes
Сеанс 2:      10% authority, add acceleration data
Result:         Better coverage through RPM range
Отправить изменения:   Yes
Сеанс 3:      10% authority, fine-tune rough spots
Result:         Smooth AFR across table
Final:          Save and burn to flash
```

**Результаты**
- Стабильный холостой ход ✓ ✓
- Плавная реакция на дроссель ✓ ✓
- Стабильный AFR ✓ ✓
- Улучшенная экономичность ✓ ✓

### Сценарий 2. Турбированный двигатель

**Цель:** обеспечить безопасность и хорошую управляемость на обычном бензине.

```
Целевой AFR:     13.5 (rich, boost safety)
Пределы влияния:      Conservative (5-8%)
Области для охвата: 
  - Idle/cruise (below 1.0 bar)
  - Mid-boost (1.0-1.3 bar)
  - High-boost (1.3+ bar) - only if safe
Длительность сеанса:   30 minutes, mixed driving
Блокировка высокого наддува: Yes (until proven safe)
Отправить изменения:   Yes with verification drive
```

**Предупреждение**
- Не создавайте высокий наддув, пока не проверите калибровку.
- Следите за IAT (температурой воздуха на впуске).
- Контролируйте систему обнаружения детонации.
- Консервативная настройка лучше чрезмерно агрессивной.

### Сценарий 3. Этаноловая смесь E85

**Цель:** настроить двигатель под высокооктановое топливо с учётом холодного запуска.

```
Целевой AFR:     12.0 (E85 stoich is lower)
Ожидайте: смесь богаче, чем на бензине.
Длительность сеанса:   45 минут (требуется больше данных).
Особые примечания:  
  - Для E85 требуется больше топлива, чем для бензина.
  - Для холодного запуска может потребоваться отдельная таблица.
  - Зимние и летние смеси E85 различаются.
Проверка:         Расход топлива должен быть выше.
```

## Советы и рекомендации

### Как получить наилучший результат
1. **Больше данных — лучше результат:** более продолжительные сеансы обычно дают лучший результат.
2. **Стабильные условия:** холодная и жаркая погода влияют на показания.
3. **Знакомая дорога:** предсказуемая скорость улучшает качество данных.
4. **Второй и третий сеансы:** первый сеанс создаёт только основу.
5. **Создавайте резервные копии:** сохраняйте калибровку до и после AutoTune.

### Сочетания клавиш
```
Ctrl+Shift+A     Open AutoTune
Ctrl+S           Сохраните калибровку.
Ctrl+Shift+E     Export data
Tab              Switch between tables
F5               Refresh heat map
```

### Когда можно остановить настройку
- Тепловая карта хорошо заполнена в обычном диапазоне движения.
- AFR находится в пределах ±1.0 от целевого значения.
- Значительные изменения больше не происходят.
- Вы уверены в качестве калибровки.
- Несколько поездок показывают стабильные результаты.

### Когда настройку следует продолжить
- На тепловой карте остаются большие пробелы.
- Колебания AFR достигают ±2.0 или больше.
- В отдельных областях данные нестабильны.
- Вы только начали (первый сеанс всегда предварительный).
- Вы изменили важные компоненты двигателя.

## Распространённые ошибки

### ❌ Слишком большие пределы влияния в начале
**Неправильно:** максимальное изменение 50% уже в первом сеансе.
**Почему:** большие неконтролируемые изменения опасны.
**Правильно:** начните с 5% и постепенно увеличивайте пределы.

### ❌ Настройка только в одном режиме
**Неправильно:** только 10 минут движения по трассе.
**Почему:** недостаточный охват данных и несбалансированная калибровка.
**Правильно:** сочетайте разные режимы движения в течение 30 минут и более.

### ❌ Игнорирование плохих данных
**Неправильно:** вся тепловая карта синяя, но настройка продолжается.
**Почему:** это признак проблемы с датчиком или механической частью двигателя.
**Правильно:** сначала найдите и устраните неисправность.

### ❌ Отсутствие проверки после отправки изменений
**Неправильно:** отправить изменения в ЭБУ и сразу сохранить файл.
**Почему:** результат может оказаться неправильным.
**Правильно:** проедьте 5 минут, проверьте AFR и только после этого сохраните калибровку.

### ❌ Настройка за один сеанс
**Неправильно:** провести один 15-минутный сеанс и считать настройку завершённой.
**Почему:** стабильность калибровки ещё не подтверждена.
**Правильно:** проведите несколько коротких сеансов для проверки результата.

# Настройка AutoTune

Подробное руководство по настройке AutoTune.

## Предварительные условия

Перед использованием AutoTune убедитесь, что:
1. Установлен и исправен **широкополосный датчик кислорода**.
2. Сигнал **AFR** подключён к аналоговому входу ЭБУ.
3. В ЭБУ настроена **таблица целевого AFR**.
4. Двигатель прогрет до рабочей температуры.
5. Базовая калибровка позволяет безопасно запустить и эксплуатировать двигатель.

## Настройка датчика

### Контроллеры широкополосного датчика

LibreTune совместима с любым широкополосным контроллером, который выдаёт аналоговый сигнал 0–5 В:
- AEM UEGO;
- Innovate LC-2;
- PLX Wideband;
- Zeitronix ZT-3.

### Кривая AFR

Убедитесь, что кривая AFR в ЭБУ соответствует выходному сигналу широкополосного контроллера:
1. Проверьте таблицу преобразования напряжения в AFR для своего контроллера.
2. Убедитесь, что она соответствует константе `afrTable` в ЭБУ.
3. При необходимости внесите корректировки.

## Параметры AutoTune

### Выбор таблицы

Выберите таблицу, которую требуется настроить:
- **VE Table 1**: основная таблица коэффициента наполнения.
- **VE Table 2**: дополнительная таблица, если она используется.
- **Другая таблица**: любая таблица, влияющая на AFR.

### Источник целевого AFR

**Из таблицы целевого AFR (рекомендуется)**
- используются целевые значения AFR, настроенные в ЭБУ;
- значения автоматически учитывают различные условия работы;
- поддерживаются разные цели для режима WOT и движения с постоянной нагрузкой.

**Фиксированное значение**
- используется постоянное целевое значение;
- настройка проще, но менее гибкая;
- подходит для первоначальных испытаний.

### Режим обновления

**Ручной**
- сначала просмотрите рекомендации;
- нажмите **Отправить**, чтобы применить их;
- наиболее безопасный вариант.

**Автоматическая отправка**
- изменения отправляются автоматически;
- сначала задайте минимальное количество попаданий;
- режим предназначен для опытных настройщиков.

## Настройка фильтров

### Фильтр RPM
- **Min RPM**: исключать данные холостого хода (обычно 800–1000 об/мин).
- **Max RPM**: исключать чрезмерно высокие обороты (около красной зоны тахометра).

### Температурный фильтр
- **Min CLT**: исключать данные холодного двигателя (от 160°F и выше — исходное значение руководства).
- Это помогает учитывать данные при стабильной температуре двигателя.

### Фильтр дроссельной заслонки
- **Min TPS**: исключать данные при закрытой заслонке (от 1%).
- Помогает не учитывать данные торможения двигателем.

### Фильтры скорости изменения
- **Max TPS Rate**: исключать резкие изменения положения дросселя (10%/с).
- Фильтруются переходные режимы.
- Снижается влияние ускорительного обогащения.

## Ограничения коррекции

### Максимальное изменение одной ячейки
- **Max Increase**: наибольшая положительная корректировка (например, 15%).
- **Max Decrease**: наибольшая отрицательная корректировка (например, 15%).

### Накопительное ограничение
- **Absolute Max**: общее отклонение от исходного значения.
- Предотвращает неконтролируемое изменение калибровки.

### Начальные значения

| Опыт | Максимальное изменение | Абсолютный предел |
|---|---:|---:|
| Начинающий | 5% | 15% |
| Средний | 10% | 25% |
| Опытный | 15% | 40% |

## Компенсация задержки Lambda

Выхлопным газам требуется время, чтобы пройти по выпускному тракту до датчика кислорода. AutoTune учитывает эту задержку:
- **На холостом ходу**: около 200 мс (длинный путь по выпускному тракту).
- **Вблизи предельных оборотов**: около 50 мс (высокая скорость потока выхлопных газов).
- LibreTune интерполирует значения между этими точками.

Кривая по умолчанию ограничивается примерно 200 мс, однако фактическая задержка выпускной системы часто составляет 400–1000 мс. Для получения наилучшего результата измерьте задержку на автомобиле с помощью инструмента [Тест задержки AFR](../tools.md) (**Инструменты → Тест задержки AFR...**) и укажите измеренное значение как фиксированную задержку Lambda в настройках AutoTune.

Также доступен вариант, учитывающий расход выхлопных газов: задержка задаётся для холостого хода/крейсерского режима и уменьшается до нижнего предела по мере роста потока. Такой подход моделирует физическую зависимость (объём выпускного тракта ÷ расход), а не использует одно постоянное значение.

## Рекомендации

1. Начинайте с небольших, консервативных ограничений коррекции.
2. Соберите данные во всех ячейках, прежде чем применять изменения.
3. Дайте данным накопиться: больше попаданий — выше точность.
4. Проверьте тепловую карту и найдите области с недостаточным охватом.
5. Проверьте изменения на стенде или в контролируемых условиях.

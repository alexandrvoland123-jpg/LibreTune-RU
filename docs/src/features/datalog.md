# Регистрация данных

LibreTune может записывать параметры работы двигателя в реальном времени для последующего анализа.

## Обзор

Регистрация данных сохраняет параметры двигателя во времени. Это позволяет:
- анализировать поездку или испытание после завершения;
- сравнивать данные до и после изменения калибровки;
- диагностировать неисправности;
- передавать записи другим специалистам.

## Начало записи

1. Подключитесь к ЭБУ.
2. Откройте **Инструменты → Начать запись** или нажмите `Ctrl+L`.
3. Настройте параметры записи:
   - **Частота записи**: количество отсчётов в секунду (10–100 Гц).
   - **Каналы**: параметры, которые требуется записывать.
4. Нажмите **Начать**.

## Остановка записи

Нажмите **Остановить запись** или повторно нажмите `Ctrl+L`.

Записи автоматически сохраняются в папку `datalogs/` текущего проекта в виде файлов `.ltlog`.

## Формат файла записи

LibreTune использует компактный бинарный формат **`.ltlog`**:
- названия каналов, единицы измерения и сигнатура INI записываются один раз в заголовке;
- отсчёты упаковываются в бинарном виде (`f32`) в блоки с проверкой CRC и сжатием zstd;
- при аварийном завершении программы или отключении USB теряется только последний незавершённый блок; предыдущие отсчёты остаются доступными;
- запись ведётся непосредственно на диск, в оперативной памяти хранится только небольшой хвост данных для графика реального времени;
- большие файлы `.ltlog` открываются потоково: график показывает прореженный предварительный просмотр, а анализ считывает нужные именованные столбцы без загрузки всего файла в память.

По сравнению с CSV размер обычно меньше примерно в **10–30 раз** (100 каналов, 50 Гц). Часовая запись, которая заняла бы около 150 МБ в CSV, обычно занимает **5–15 МБ** в `.ltlog`.

Также можно **открывать** старые файлы LibreTune `.csv`, текстовые экспорты TunerStudio `.msl` и бинарные журналы TunerStudio `.mlg`.

Встроенная запись больше не создаёт CSV: такой формат быстро увеличивается из-за хранения каждого значения в виде текста.

## Просмотр журнала данных

### Открытие записи

1. Откройте **Инструменты → Просмотр журнала данных**.
2. Нажмите **Открыть запись**.
3. Выберите файл `.ltlog` либо старый `.csv`, `.msl` или `.mlg` TunerStudio.

### Управление воспроизведением

| Элемент | Описание |
|---|---|
| ▶️ Воспроизведение | Воспроизведение записи в реальном времени |
| ⏸️ Пауза | Остановка воспроизведения |
| ⏪⏩ Перемотка | Переход вперёд или назад |
| Ползунок | Переход к любой позиции записи |
| Скорость | Скорость воспроизведения 0,5x, 1x или 2x |

### Синхронизация представлений

Во время воспроизведения записи:
- панели приборов обновляются сохранёнными значениями;
- в таблицах подсвечивается текущая рабочая ячейка;
- графики показывают текущую позицию записи.

## Автоматическая запись

Настройте автоматическую запись в параметрах:
- **Начинать при подключении**: запуск записи после подключения ЭБУ.
- **Максимальная длительность записи**: ограничение размера файла.
- **Останавливать при отключении**: завершение записи после разрыва соединения.

## Советы по анализу записей

### Поиск неисправностей
1. Откройте запись в просмотрщике.
2. Найдите отклонения AFR.
3. Проверьте пропадание сигналов датчиков.
4. Сравните ожидаемые и фактические значения.

### Проверка калибровки
1. Запишите исходный заезд или режим работы.
2. Измените калибровку.
3. Повторите тот же режим и запишите данные снова.
4. Сравните две записи.

### Обмен записями

Файлы `.ltlog` открываются в LibreTune. Старые CSV также остаются доступными для чтения. Файлы TunerStudio `.msl` и `.mlg` можно импортировать для анализа.

## Экспорт данных калибровки

Чтобы экспортировать всю калибровку в CSV:
1. Откройте **Файл → Экспортировать калибровку в CSV**.
2. Укажите имя файла.
3. Все константы будут экспортированы вместе с метаданными.

## Импорт данных калибровки

Чтобы импортировать значения из CSV:
1. Откройте **Файл → Импортировать калибровку из CSV**.
2. Выберите ранее экспортированный CSV.
3. Значения будут проверены и применены.

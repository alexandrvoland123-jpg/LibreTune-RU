# Перенос калибровок и отслеживание версий INI

LibreTune автоматически сохраняет информацию о том, какое описание ЭБУ (INI-файл) использовалось при сохранении калибровки, и определяет, изменилась ли версия INI. Это помогает безопасно переносить калибровки между версиями прошивки.

## Как это работает

При каждом сохранении калибровки LibreTune записывает:
- **Сигнатуру INI** — идентификатор версии прошивки.
- **Структурный хеш** всех определений констант (имена, типы, смещения и коэффициенты масштабирования).
- **Манифест констант** — перечень всех настроек, содержащихся в INI.

Если позднее открыть эту калибровку с другим INI-файлом (например, после обновления прошивки), LibreTune сравнит сохранённый манифест с текущим INI и сформирует **отчёт о переносе**, в котором будут перечислены все обнаруженные изменения.

## Диалог отчёта о переносе

При обнаружении несовпадения версий автоматически открывается диалог отчёта. В нём отображаются следующие уровни серьёзности:

### Уровни серьёзности

| Уровень | Цвет | Значение |
|---|---|---|
| **Нет** | — | Изменения не обнаружены, калибровка полностью совместима |
| **Низкий** | Синий | В новой версии INI добавлены константы; существующие значения не затронуты |
| **Средний** | Оранжевый | Изменились коэффициенты масштабирования или смещения; для получения прежнего физического результата значения может потребоваться скорректировать |
| **Высокий** | Красный | Изменились типы или удалены константы; некоторые настройки могут быть потеряны или интерпретированы неправильно |

### Категории изменений

Диалог группирует изменения по сворачиваемым разделам:
- **Изменение типов** (критическое) — изменился тип данных константы (например, U08 → S16). Такие изменения требуют внимательной проверки: значения могут интерпретироваться иначе.
- **Изменение масштабирования** (предупреждение) — изменился коэффициент масштабирования или смещения. То же исходное значение может соответствовать другому физическому значению.
- **Удалённые константы** — настройки, присутствовавшие в старом INI, но отсутствующие в новом. Эти значения будут потеряны.
- **Новые константы** — настройки, добавленные в новую версию INI. Для них будут использованы значения по умолчанию.

В каждом разделе показывается не более 20 элементов. Если изменений больше, отображается надпись «…и ещё N».

### Действия

- **Dismiss:** закрыть диалог и продолжить работу с калибровкой без изменений.
- **Continue with Tune:** подтвердить ознакомление с изменениями и продолжить редактирование.

## Когда запускается проверка переноса

Проверка выполняется, когда:
1. Вы **открываете калибровку**, сохранённую с другой версией INI.
2. Вы **меняете INI-файл** для открытого проекта (через настройки или диалог несовпадения сигнатуры).
3. Вы **обновляете прошивку ЭБУ** и подключаетесь заново с новым INI.

## Рекомендации

### Перед обновлением прошивки

1. **Создайте точку восстановления** (File → Create Restore Point), чтобы сохранить текущую калибровку.
2. **Экспортируйте калибровку в CSV** (File → Export Tune as CSV), чтобы получить резервную копию в читаемом виде.
3. Обновите прошивку ЭБУ.
4. Загрузите или импортируйте новый INI-файл, соответствующий версии прошивки.
5. Откройте калибровку — отчёт о переносе покажет, что изменилось.

### Проверка изменений

- **Низкий уровень:** обычно можно продолжать работу. Для новых констант будут использованы разумные значения по умолчанию.
- **Средний уровень:** внимательно проверьте изменения масштабирования. При другом коэффициенте одно и то же исходное значение соответствует другому физическому значению (например, шаг множителя обогащения топлива изменился с 0.1 до 0.01).
- **Высокий уровень:** отдельно проверьте каждое изменение типа. Убедитесь, что исходные значения остаются допустимыми. Возможно, некоторые настройки придётся ввести заново.

### После переноса

1. Проверьте основные таблицы (VE, зажигания и целевых AFR), чтобы убедиться в корректности значений.
2. Используйте **Table Comparison** (Tools → Table Comparison), чтобы сравнить перенесённую калибровку с заведомо исправной базовой версией.
3. Сохраните калибровку, чтобы обновить метаданные INI для последующих переносов.

## Технические подробности

- Метаданные INI хранятся в файле калибровки `.msq` в XML-разделах `<iniMetadata>` и `<constantManifest>`.
- Структурный хеш SHA-256 рассчитывается по всем определениям констант, не относящимся к PC.
- Отчёты о переносе формируются в памяти и не сохраняются: они показываются один раз при каждом обнаружении несовпадения.
- Для поддержки метаданных INI версия формата файла калибровки изменена с `1.0` на `1.1`.

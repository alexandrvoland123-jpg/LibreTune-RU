# Создание панелей приборов

Создание собственных макетов панелей с нуля.

## Создание новой панели

1. Откройте **Вид → Панель приборов → Новая панель**.
2. Либо щёлкните правой кнопкой мыши по списку панелей и выберите **Создать**.
3. Выберите вариант:
   - **Пустая** — начать с чистого листа.
   - **Из шаблона** — использовать готовый макет.
   - **Копировать текущую** — создать копию открытой панели.

## Режим конструктора

Чтобы изменить расположение элементов, включите режим конструктора:
1. Щёлкните правой кнопкой мыши по фону панели.
2. Выберите **Режим конструктора**.
3. Появление рамки означает, что режим редактирования включён.

## Добавление приборов

### Через контекстное меню
1. Щёлкните правой кнопкой мыши по пустой области.
2. Выберите **Добавить прибор**.
3. Укажите тип прибора.
4. Выберите канал данных.
5. Прибор появится в месте щелчка.

### Перетаскивание из боковой панели
1. Убедитесь, что включён **Режим конструктора**.
2. Найдите нужный канал в списке каналов боковой панели.
3. Перетащите название канала на рабочую область панели.
4. Отпустите кнопку мыши в месте размещения прибора.
5. Прибор будет создан автоматически с каналом, единицами измерения, минимальным и максимальным значениями и предупредительными зонами из определения INI.

При перетаскивании приборы автоматически:
- привязываются к сетке панели, если включена привязка;
- наследуют метаданные INI (единицы измерения, минимум, максимум и пороги предупреждений);
- добавляются в историю отмены и повтора действий.

### Через каталог приборов
1. Откройте каталог приборов (**Вид → Каталог приборов**).
2. Перетащите прибор на панель.
3. Отпустите его в нужном месте.

## Категории приборов

Приборы сгруппированы по типам:
- **Двигатель**: RPM, MAP, TPS.
- **Топливо**: AFR, длительность импульса, коэффициент заполнения.
- **Зажигание**: угол опережения, время накопления катушки (dwell).
- **Датчики**: температуры и давления.
- **Расчётные параметры**: мощность, крутящий момент, скорость.

## Советы по размещению

### Выравнивание по сетке
- Включите **Привязку к сетке**, чтобы аккуратно выровнять элементы.
- Размер сетки настраивается в параметрах.

### Группировка
Размещайте связанные приборы рядом:
- приборы топливной системы — в одной области;
- датчики температуры — вместе;
- диагностические приборы — отдельно.

### Иерархия
- Самый крупный прибор должен отображать наиболее важный параметр.
- Центральная область — для основных показаний.
- По краям — второстепенная информация.

## Настройка фона

1. Щёлкните правой кнопкой мыши по панели.
2. Выберите **Фон**.
3. Укажите вариант:
   - **Сплошной цвет** — выбрать один цвет.
   - **Градиент** — плавный переход между двумя цветами.
   - **Изображение** — загрузить файл изображения.

## Сохранение панелей

1. Нажмите **Выйти из режима конструктора** или клавишу Escape.
2. Панель сохраняется автоматически.
3. Либо щёлкните правой кнопкой мыши и выберите **Сохранить панель как...**.

### Файлы панелей

Панели сохраняются в формате `.ltdash.xml`:
- в папке проекта;
- либо в общей папке панелей.

## Обмен панелями

Экспорт панели:
1. Щёлкните правой кнопкой мыши по списку панелей.
2. Выберите **Экспорт панели**.
3. Укажите место сохранения.

Импорт общей панели:
1. Выберите **Файл → Импорт панели**.
2. Укажите файл `.ltdash.xml` или `.dash`.
3. Панель появится в списке.

## Шаблоны панелей

Чтобы создать шаблон для повторного использования:
1. Создайте макет.
2. Выберите **Сохранить как** и укажите имя шаблона.
3. Установите флажок **Сохранить как шаблон**.
4. Шаблон станет доступен в диалоге создания новой панели.

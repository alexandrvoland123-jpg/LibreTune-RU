# Использование панелей приборов

Подробное руководство по просмотру панелей и взаимодействию с ними.

## Структура панели

Каждая панель может содержать:
- **Приборы** — отображают числовые значения.
- **Индикаторы** — показывают состояния включено/выключено.
- **Графики** — отображают историю значений.
- **Фон** — необязательное изображение или цвет.

## Просмотр данных

### Обновление в реальном времени

При подключении к ЭБУ:
- все приборы обновляются автоматически;
- частота по умолчанию — 10 обновлений в секунду;
- при необходимости её можно изменить в настройках.

### Отображение значений

Каждый прибор показывает:
- текущее значение;
- единицу измерения;
- состояние, обозначенное цветом.

### Цвета состояния

- **Зелёный / норма** — значение находится в безопасном диапазоне.
- **Жёлтый / предупреждение** — значение приближается к предельному.
- **Красный / опасность** — значение вышло за безопасные пределы.

## Взаимодействие с приборами

### Наведение указателя

При наведении на прибор отображаются:
- полное название канала;
- настроенные минимальное и максимальное значения;
- текущее значение с большей точностью.

### Щелчок

Щелчок по прибору позволяет:
- открыть связанную таблицу, если она существует;
- просмотреть подробности значения;
- открыть настройки прибора.

### Двойной щелчок

Дважды щёлкните по прибору, чтобы открыть его в полноэкранном режиме.

## Выбор панели

Чтобы переключиться на другую панель:
1. Нажмите раскрывающийся список в заголовке.
2. Выберите название панели.
3. Отображение переключится немедленно.

### Категории

Панели сгруппированы по категориям:
- **Встроенные** — стандартные панели LibreTune.
- **Пользовательские** — созданные вами панели.
- **Импортированные** — панели из TunerStudio.

## Полноэкранный режим

1. Дважды щёлкните по фону панели.
2. Панель развернётся на весь экран.
3. Нажмите Escape или дважды щёлкните мышью, чтобы выйти.

## Несколько мониторов

Чтобы вынести панель на отдельный монитор:
1. Нажмите значок отсоединения (↗️) на панели вкладок.
2. Панель откроется в новом окне.
3. Перетащите окно на нужный монитор.
4. Нажмите значок возврата (↙️), чтобы вернуть панель в основное окно.

> **Примечание:** основная вкладка «Панель приборов» защищена от отсоединения и случайного закрытия. Если она пропала, откройте её через **Вид → Панель приборов**.

## Производительность и сглаживание

Панели перерисовывают каждый прибор по ограниченному таймеру со сдвигом фазы, а не при каждом поступившем отсчёте. Это позволяет контролировать нагрузку на процессор и расход батареи ноутбука, даже если ЭБУ передаёт данные быстрее, чем требуется для отображения.

### Частота обновления приборов

Параметр **Настройки → Общие → Панель приборов → Частота обновления приборов** ограничивает частоту перерисовки:
- **10 Гц (экономия батареи)** — настройка автомобиля при работе ноутбука от аккумулятора.
- **15–25 Гц** — сбалансированный режим.
- **30 Гц (по умолчанию)** — наиболее плавное движение.

Таймеры перерисовки сдвинуты относительно друг друга, поэтому приборы не обновляются все в один кадр. Движение стрелок использует EMA (экспоненциальное скользящее среднее), зависящее от времени. Поэтому движение выглядит одинаково при любой частоте обновления; меняется только частота отдельных шагов.

### Выделение кратковременных скачков

Короткие импульсы, которые могли бы исчезнуть из-за сглаживания, не теряются. Если исходное значение резко отклоняется от сглаженного, числовое показание кратковременно подсвечивается критическим цветом, а на линейном графике появляется цветная точка в исходном положении. Это помогает заметить кратковременные отклонения, например скачок в сторону бедной смеси, не превращая график в подобие звуковой волны.

### Выравнивание значений приборов по правому краю

Параметр **Настройки → Общие → Панель приборов → Выравнивать значения приборов по правому краю** сохраняет положение чисел при изменении количества цифр или знака (например, при переходе угла опережения зажигания через 0°). Цифровые индикаторы и шкалы закрепляют значения у фиксированного правого края; аналоговые приборы дополняют значения пробелами до фиксированной ширины, чтобы они оставались по центру и не смещались.

## Советы

### Уберите лишнее
- Оставляйте только необходимые приборы.
- Используйте крупные приборы для критически важных параметров.
- Группируйте связанные показания.

### Настройте панель под задачу
- **Настройка двигателя**: AFR, VE и коррекции.
- **Гонки**: крупные RPM и скорость, только необходимые предупреждения.
- **Диагностика**: датчики и коэффициенты заполнения.

# Настройка приборов

Настройка внешнего вида и поведения отдельных приборов.

## Открытие настроек прибора

1. Включите режим конструктора (щелчок правой кнопкой мыши → **Режим конструктора**).
2. Щёлкните правой кнопкой мыши по прибору.
3. Выберите **Настроить прибор**.

## Свойства прибора

### Канал данных

Выберите значение ЭБУ, которое требуется отображать:
- RPM, MAP, TPS, AFR и другие;
- любой канал, определённый в файле INI.

### Диапазоны значений

| Свойство | Описание |
|---|---|
| Минимум | Наименьшее отображаемое значение |
| Максимум | Наибольшее отображаемое значение |
| Нижний порог предупреждения | Граница предупредительной зоны снизу |
| Верхний порог предупреждения | Граница предупредительной зоны сверху |
| Нижний критический порог | Нижняя граница опасной зоны |
| Верхний критический порог | Верхняя граница опасной зоны |

### Внешний вид

| Свойство | Описание |
|---|---|
| Тип прибора | Аналоговый, цифровой, шкала и т. д. |
| Заголовок | Отображаемое название |
| Единицы измерения | Обозначение единиц (RPM, °F и т. д.) |
| Число знаков после запятой | Точность отображения |

### Цвета

| Свойство | Описание |
|---|---|
| Обычный цвет | Цвет безопасного диапазона |
| Цвет предупреждения | Цвет предупредительной зоны |
| Цвет опасности | Цвет опасной зоны |
| Фон | Цвет фона прибора |
| Ободок | Цвет рамки |

## Типы приборов

### Аналоговый прибор
- Классический круглый циферблат со стрелкой.
- Лучше всего подходит для RPM, скорости и давления наддува.
- Хорошо показывает относительное положение значения в диапазоне.

### Цифровой индикатор
- Числовое отображение в стиле LCD.
- Подходит для AFR, температуры и напряжения.
- Показывает точные значения.

### Шкальный индикатор
- Горизонтальная или вертикальная полоса заполнения.
- Подходит для температуры охлаждающей жидкости и уровня топлива.
- Удобен для компактных макетов.

### Дуговой индикатор
- Индикатор в виде изогнутой дуги.
- Подходит для стилизованных панелей.
- Обеспечивает наглядное отображение.

### Линейный график
- История изменения значения во времени.
- Подходит для анализа тенденций и истории Lambda.
- Показывает недавние изменения.

## Изменение размера приборов

В режиме конструктора:
1. Щёлкните прибор, чтобы выделить его.
2. Перетаскивайте угловые маркеры для изменения размера.
3. Удерживайте Shift, чтобы сохранить соотношение сторон.

## Перемещение приборов

В режиме конструктора:
1. Перетащите прибор за центральную область.
2. При необходимости используйте привязку к сетке.
3. Для точной настройки положения используйте клавиши со стрелками.

## Копирование приборов

1. Щёлкните правой кнопкой мыши по прибору.
2. Выберите **Дублировать**.
3. Копия появится со смещением относительно оригинала.
4. Измените канал или настройки копии.

## Удаление приборов

1. Выберите прибор.
2. Нажмите Delete.
3. Либо щёлкните правой кнопкой мыши и выберите **Удалить прибор**.

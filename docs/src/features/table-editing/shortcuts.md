# Горячие клавиши

Полный справочник сочетаний клавиш для редактирования таблиц.

## Навигация

| Сочетание | Действие |
|---|---|
| Стрелки | Перемещение выделения |
| Tab | Переход к следующей ячейке |
| Shift+Tab | Переход к предыдущей ячейке |
| Home | Переход к первой ячейке строки |
| End | Переход к последней ячейке строки |
| Ctrl+Home | Переход к первой ячейке таблицы |
| Ctrl+End | Переход к последней ячейке таблицы |
| Page Up | Прокрутка вверх на одну страницу |
| Page Down | Прокрутка вниз на одну страницу |

## Выделение

| Сочетание | Действие |
|---|---|
| Shift+Стрелка | Расширение выделения |
| Ctrl+A | Выделить все ячейки |
| Ctrl+Щелчок | Добавить ячейку в выделение или убрать её из выделения |
| Shift+Щелчок | Расширить выделение до выбранной ячейки |
| Escape | Снять выделение |

## Редактирование

| Сочетание | Действие |
|---|---|
| Enter | Редактировать выбранную ячейку |
| Delete | Очистить выбранные ячейки |
| Backspace | Очистить и перейти к редактированию |
| `+` или `>` | Увеличить значение на шаг |
| `-` или `<` | Уменьшить значение на шаг |
| Shift + (`+`/`-`) | Увеличить или уменьшить значение с шагом в 10 раз больше |
| `=` | Уравнять (среднее значение) |
| `*` | Масштабировать с заданным коэффициентом |
| `/` | Интерполировать |
| S | Сгладить выделение |

## Буфер обмена

| Сочетание | Действие |
|---|---|
| Ctrl+C | Копировать выделение |
| Ctrl+V | Вставить |
| Ctrl+Shift+V | Специальная вставка |
| Ctrl+X | Вырезать выделение |

## История изменений

| Сочетание | Действие |
|---|---|
| Ctrl+Z | Отменить |
| Ctrl+Y | Повторить |
| Ctrl+Shift+Z | Повторить (альтернативное сочетание) |

## Вид

| Сочетание | Действие |
|---|---|
| Ctrl+0 | Масштаб по размеру окна |
| Ctrl++ | Увеличить масштаб |
| Ctrl+- | Уменьшить масштаб |
| F | Переключить режим Follow |
| 3 | Переключить трёхмерный вид |

## Файл

| Сочетание | Действие |
|---|---|
| Ctrl+S | Сохранить калибровку |
| Ctrl+B | Записать калибровку в ЭБУ |

## Настройка сочетаний

Сочетания клавиш можно изменить в разделе **Настройки → Горячие клавиши**.

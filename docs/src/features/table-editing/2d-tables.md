# Двумерные таблицы

Подробное руководство по редактированию двумерных калибровочных таблиц.

## Как устроены двумерные таблицы

Двумерная таблица связывает две входные переменные с выходным значением:
- **Ось X (столбцы)**: обычно обороты двигателя (RPM).
- **Ось Y (строки)**: обычно нагрузка (MAP, TPS и т. д.).
- **Значения Z (ячейки)**: калибруемый выходной параметр.

## Выделение ячеек

### Мышью
- **Щелчок**: выбрать одну ячейку.
- **Щелчок + перетаскивание**: выделить прямоугольную область.
- **Ctrl + щелчок**: добавить ячейку в выделение или убрать её.
- **Shift + щелчок**: расширить выделение до выбранной ячейки.

### Клавиатурой
- **Стрелки**: перемещение выделения.
- **Shift + стрелка**: расширение выделения.
- **Ctrl + A**: выделить все ячейки.

## Редактирование ячеек

### Изменение одной ячейки
1. Выберите ячейку.
2. Введите число.
3. Нажмите Enter.

### Увеличение и уменьшение
- `+` или `>`: увеличить на один шаг.
- `-` или `<`: уменьшить на один шаг.
- Удерживайте **Shift**, чтобы изменить шаг в 10 раз.

### Групповые операции

| Клавиша | Операция | Описание |
|---|---|---|
| `=` | Уравнять (Set Equal) | Среднее значение выбранных ячеек |
| `*` | Масштабировать (Scale) | Умножить на коэффициент |
| `/` | Интерполировать (Interpolate) | Билинейная интерполяция |
| `S` | Сгладить (Smooth) | Гауссово размытие |

## Копирование и вставка

### Обычное копирование и вставка
1. Выделите ячейки.
2. Нажмите `Ctrl+C` для копирования.
3. Выберите место назначения.
4. Нажмите `Ctrl+V` для вставки.

### Специальная вставка
Сочетание `Ctrl+Shift+V` открывает параметры вставки:
- **Заменить (Replace)**: обычная вставка.
- **Добавить (Add)**: прибавить вставленные значения к существующим.
- **Умножить (Multiply)**: умножить на вставленные значения.
- **Усреднить (Average)**: вычислить среднее с существующими значениями.

## Цвета ячеек

Цвет ячеек зависит от значения:
- **Тёмно-синий**: низкие значения.
- **Зелёный/жёлтый**: средние значения.
- **Красный**: высокие значения.

Цветовая шкала рассчитывается по минимальному и максимальному значениям таблицы.

## Режим Follow

При подключении к ЭБУ:
1. Нажмите значок перекрестия (или клавишу `F`).
2. Текущая рабочая ячейка будет подсвечена.
3. Значения обновляются в реальном времени.

По сетке отображается **линия следа** через недавно посещённые ячейки; она заканчивается яркой точкой на текущей ячейке. Старые участки постепенно затухают в соответствии с параметром *Trail fade*. Если в INI таблицы не заданы каналы осей, для положения курсора используются стандартные каналы `rpm` и `map`.

## Советы

### Стратегия сглаживания
1. Сначала добейтесь правильной общей формы таблицы.
2. Используйте Smooth для устранения резких переходов.
3. Затем уточняйте отдельные ячейки.

### Стратегия масштабирования
1. Выделите всю таблицу или нужную область.
2. Масштабируйте её на процент (например, `1.05` для увеличения на 5%).
3. Это удобно для общей корректировки.

### Стратегия интерполяции
1. Задайте заведомо правильные значения в угловых или крайних ячейках.
2. Выделите область между ними.
3. Выполните интерполяцию для заполнения промежуточных значений.

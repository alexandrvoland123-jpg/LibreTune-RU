# Панели приборов

Панели приборов отображают параметры двигателя в реальном времени с помощью настраиваемых приборов и индикаторов.

## Обзор

Панели LibreTune — это настраиваемые наборы приборов, индикаторов и графиков, отображающих текущие данные ЭБУ.

## Встроенные панели

В LibreTune предусмотрены три готовые панели.

### Базовая панель

Основные параметры для повседневного контроля:
- крупный аналоговый тахометр;
- цифровое отображение AFR;
- индикаторы температуры охлаждающей жидкости и воздуха на впуске (IAT);
- индикатор давления MAP;
- значения напряжения аккумулятора, угла опережения зажигания, VE и длительности импульса форсунок.

### Спортивная панель

Компоновка для движения на треке:
- крупный центральный тахометр;
- индикаторы давления масла и температуры охлаждающей жидкости;
- скорость, AFR, наддув и параметры топлива.

### Панель настройки

Компоновка для калибровки двигателя:
- разные типы приборов для различных параметров;
- график истории Lambda;
- отображение коэффициентов коррекции;
- индикаторы EGT и коэффициента заполнения (duty cycle).

## Открытие панели

Вкладка панели приборов всегда присутствует, когда открыт проект. Если она отсутствует:

1. Выберите **Вид → Панель приборов**, чтобы открыть её снова; либо
2. Откройте проект — вкладка панели будет создана автоматически.

> **Примечание:** вкладка панели защищена от случайного закрытия. Кнопка закрытия (×) скрыта, а щелчок средней кнопкой мыши не закрывает её.

## Переключение панелей

1. Нажмите селектор панели (раскрывающийся список в заголовке).
2. Выберите нужную панель из списка.
3. Отображение обновится сразу.

## Данные в реальном времени

При подключении к ЭБУ:
- приборы обновляются автоматически (по умолчанию 10 Гц);
- значения окрашиваются в зависимости от состояния (норма, предупреждение, опасность);
- режим Follow выделяет текущие условия работы двигателя.

## Типы приборов

LibreTune поддерживает 13 стандартных типов приборов:

| Тип | Описание |
|---|---|
| **Аналоговый прибор** | Классическая круглая шкала с металлическим ободком и градиентной стрелкой |
| **Цифровой индикатор** | Числовое значение в стиле LCD с металлической рамкой |
| **Горизонтальная шкала** | Горизонтальная полоса прогресса с закруглёнными краями и градиентной заливкой |
| **Вертикальная шкала** | Вертикальная полоса с делениями и объёмным эффектом |
| **Дуговой индикатор** | Изогнутая шкала со светящимся указателем и зонами предупреждения |
| **Горизонтальный линейный индикатор** | Горизонтальная линия с градиентной шкалой |
| **Вертикальная сегментная шкала** | Сегментированная вертикальная полоса с отдельной окраской зон |
| **Линейный график** | График изменения параметра во времени с градиентной заливкой |
| **Гистограмма** | Столбчатое распределение значений относительно текущего значения |
| **Круговой прибор** | Круглая шкала с дугой 270° и делениями |
| **Сегментный круговой прибор** | Круглая шкала с разделённой на сегменты дугой |
| **Указатель уровня топлива** | Специализированный индикатор уровня топлива |
| **Тахометр** | Прибор оборотов двигателя с красной зоной |

## Зоны шкал

Приборы могут отображать цветовые зоны:
- **Зелёная** — нормальный рабочий диапазон.
- **Жёлтая/оранжевая** — зона предупреждения.
- **Красная** — опасная зона.

## Режим конструктора

Чтобы изменить расположение приборов:
1. Щёлкните правой кнопкой мыши по фону панели.
2. Выберите **Режим конструктора (Designer Mode)**.
3. Перетаскивайте приборы, чтобы изменить их положение.
4. Изменяйте размер, перетаскивая края прибора.
5. Щёлкните правой кнопкой мыши по прибору, чтобы открыть его параметры.
6. После настройки нажмите **Выйти из режима конструктора (Exit Designer)**.

## Параметры контекстного меню

Щёлкните правой кнопкой мыши по прибору или фону панели:

| Пункт | Назначение |
|---|---|
| **Перезагрузить стандартные приборы** | Восстановить конфигурацию по умолчанию |
| **Приборы LibreTune** | Добавить приборы из определения INI |
| **Сбросить значение** | Очистить отображаемое значение |
| **Фон** | Изменить цвет или изображение фона |
| **Сглаживание** | Включить или выключить сглаживание изображения |
| **Режим конструктора** | Включить или выключить редактирование расположения |
| **Демонстрация приборов** | Анимировать приборы с помощью имитационных данных |

## Импорт панелей

LibreTune может импортировать макеты панелей TunerStudio:
1. Выберите **Файл → Импорт панели приборов**.
2. Укажите файл `.dash`.
3. Макет будет преобразован и отображён в LibreTune.

## Создание собственной панели

1. Начните с шаблона или пустой панели.
2. Включите режим конструктора.
3. Щёлкните правой кнопкой мыши и выберите **Добавить прибор**.
4. Выберите канал данных.
5. Настройте свойства прибора.
6. Сохраните панель.

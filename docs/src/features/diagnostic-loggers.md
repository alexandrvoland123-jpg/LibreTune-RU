# Диагностические регистраторы

В LibreTune есть специализированные инструменты регистрации данных для расширенной диагностики ЭБУ и анализа работы двигателя.

## Регистратор зубьев (Tooth Logger)

Tooth Logger записывает временные интервалы между отдельными зубьями задающего диска коленчатого вала для анализа зажигания и сигналов синхронизации.

### Обзор

Регистратор зубьев фиксирует:
- угловое положение и время прохождения зубьев;
- интервал между соседними зубьями;
- качество сигнала датчика коленчатого вала;
- точность расчёта оборотов двигателя;
- целостность сигнала триггера.

### Когда использовать

- **Настройка триггера:** проверка конфигурации датчиков коленчатого и распределительного валов.
- **Диагностика зажигания:** поиск ошибок или смещения угла.
- **Качество сигнала:** обнаружение помех и периодических пропаданий сигнала.
- **Точность RPM:** сравнение расчётных оборотов ЭБУ с фактическими.
- **Диагностика пропусков воспламенения:** поиск связанных с ними проблем синхронизации.

### Порядок работы

1. **Откройте Tooth Logger.**
   ```
   Tuning → Tooth Logger
   ```
2. **Настройте запись.**
   - Выберите тип триггера (360°, 720° или пользовательский).
   - Задайте длительность записи (1–10 секунд).
   - Выберите зубья для записи (все или определённый диапазон).
3. **Запустите запись.**
   - Нажмите **Start**.
   - Двигатель должен работать с постоянными оборотами.
   - Дождитесь завершения сбора данных.
4. **Проанализируйте результат.**
   - Просмотрите график времени прохождения зубьев.
   - Проверьте равномерность интервалов.
   - Найдите шумы или пропуски сигнала.
   - Проверьте расчёт оборотов.

### Интерпретация результатов

#### Хорошие данные
```
✓ Зубья расположены равномерно
✓ Интервалы между зубьями стабильны
✓ Пропусков сигнала нет
✓ Фронты нарастания и спада чёткие
✓ Расчётные обороты совпадают с фактическими
```

#### Плохие данные
```
✗ Неравномерное расположение зубьев
✗ Интервалы меняются
✗ Зубья отсутствуют или присутствует шум
✗ Фронты сигнала зашумлены
✗ Обороты скачут или колеблются
```

### Типичные проблемы

**Проблема:** зубья не обнаруживаются.
- Проверьте проводку датчика коленвала.
- Проверьте зазор датчика (обычно 0.5–1.5 мм).
- Проверьте сопротивление и напряжение датчика.
- Проверьте настройки триггера ЭБУ в INI.

**Проблема:** сигнал зубьев зашумлён.
- Проложите провода датчика коленвала подальше от проводов зажигания.
- Проверьте экран кабеля на обрывы и повреждения.
- Проверьте напряжение питания датчика.
- Проверьте настройки входа сигнала ЭБУ.

**Проблема:** отсутствуют отдельные зубья.
- Возможно физическое повреждение задающего диска коленвала.
- ЭБУ может отфильтровывать сигнал как помеху.
- Контакт в проводке может быть ослаблен или окислен.
- Зазор датчика может быть слишком большим.

## Комплексный регистратор (Composite Logger)

Composite Logger одновременно записывает несколько сигналов двигателя, позволяя комплексно анализировать его работу.

### Обзор

Комплексная регистрация фиксирует:
- первичный и вторичный сигналы триггера;
- состояние синхронизации;
- уровни напряжения;
- временные соотношения сигналов;
- информацию о коэффициенте заполнения (duty cycle).

### Когда использовать

- **Диагностика синхронизации:** проверка взаимного положения первичного и вторичного сигналов.
- **Фазы ГРМ:** проверка положения датчика распредвала относительно коленвала.
- **Несколько каналов:** совместный анализ нескольких источников триггера.
- **Попеременный впрыск:** проверка чередования импульсов форсунок.
- **Управление турбонаддувом:** контроль сигналов наддува и вестгейта.

### Порядок работы

1. **Откройте Composite Logger.**
   ```
   Tuning → Composite Logger
   ```
2. **Выберите каналы.**
   - Первичный триггер.
   - Вторичный триггер (распредвал).
   - Вход напряжения (необязательно).
   - Сигнал duty cycle (необязательно).
3. **Настройте запись.**
   - Длительность (рекомендуется 5–30 секунд).
   - Частота дискретизации (500 Гц – 10 кГц).
   - Условие запуска: начало поступления данных или определённое событие.
4. **Запишите данные.**
   - Нажмите **Start**.
   - Дождитесь записи данных.
   - При необходимости изменяйте режим работы двигателя.
   - Остановите запись.
5. **Проанализируйте данные.**
   - Просмотрите наложенные друг на друга осциллограммы.
   - Проверьте синхронизацию сигналов.
   - Измерьте временные соотношения.
   - Экспортируйте данные для дальнейшего анализа.

### Как понимать сигналы

#### Сигналы триггера
- **Первичный (коленвал):** основная временная опора; импульс формируется для каждого зуба.
- **Вторичный (распредвал):** сигнал синхронизации, который появляется один раз за цикл двигателя.
- **Соотношение:** вторичный сигнал должен появляться при определённом угле коленчатого вала.

#### Сигналы напряжения
- **Базовый уровень 0 В:** логический ноль (масса).
- **Номинальный уровень 5 В:** логическая единица (сигнал присутствует).
- **Промежуточный уровень:** аналоговое напряжение (датчики давления, AFR и т. д.).

#### Коэффициент заполнения
- **0%:** сигнал всегда выключен.
- **50%:** половину времени включён, половину выключен (например, импульс форсунки).
- **100%:** сигнал всегда включён.

### Интерпретация результатов

#### Хорошая синхронизация
```
✓ Зубья первичного сигнала регулярны
✓ Вторичный сигнал находится в ожидаемом положении
✓ Напряжение стабильно соответствует логическим уровням
✓ Duty cycle пропорционален нагрузке двигателя
```

#### Проблемы синхронизации
```
✗ Вторичный сигнал не синхронизирован
✗ Сигнал распредвала слишком опережает или запаздывает относительно коленвала
✗ Вторичный сигнал не обнаружен
✗ Синхронизация периодически теряется
```

### Типичные проблемы

**Нет синхронизации (красный значок):**
- датчик распредвала не установлен;
- проводка датчика распредвала ослаблена;
- датчик распредвала неисправен;
- настройки ЭБУ не соответствуют конфигурации;
- механические фазы распредвала выставлены неправильно.

**Синхронизация смещается:**
- ремень или цепь ГРМ изношены (перескок фаз);
- сигнал датчика распредвала слабый;
- электромагнитные помехи в проводке;
- окно синхронизации ЭБУ слишком узкое.

**Зашумлённый сигнал:**
- проверьте экранирование кабелей;
- проверьте питание датчика;
- проверьте зазор датчика;
- проверьте соединения массы.

Основной доступ к нему находится в **View → Data Logger**, но диагностические журналы также можно открыть из этого раздела.

Полное описание приведено в разделе [Регистрация данных](./datalog.md).

## Экспорт данных регистраторов

Данные всех регистраторов можно экспортировать для внешнего анализа.

**Поддерживаемые форматы:**
- CSV (совместим с Excel/LibreOffice);
- TXT (обычный текст);
- PNG (снимки графиков).

**Порядок экспорта:**
1. Завершите запись.
2. Нажмите **Export**.
3. Выберите формат и расположение файла.
4. Файл будет сохранён с временной меткой.

## Советы по расширенной регистрации

### Рекомендации

1. **Прогрейте двигатель:** дождитесь рабочей температуры ЭБУ.
2. **Стабильный режим:** во время записи поддерживайте постоянные обороты.
3. **Несколько записей:** выполните несколько запусков записи, чтобы проверить повторяемость результатов.
4. **Сохраните исходные данные:** перед изменениями сохраните запись с исправной работой.
5. **Сравнивайте:** используйте записи до и после настройки, чтобы проверить результат.

### Порядок поиска неисправностей

1. **Начните с простого:** запишите только первичный сигнал триггера.
2. **Добавьте второй сигнал:** включите вторичный канал.
3. **Изменяйте режимы:** выполните запись на холостом ходу, при 3000 и 5000 об/мин.
4. **Документируйте проблемы:** отмечайте все замеченные отклонения.
5. **Проверьте исправления:** после изменений выполните повторную запись.

### Совместное использование с другими инструментами

- **Tooth Logger + AutoTune:** проверка стабильности синхронизации во время настройки.
- **Composite Logger + Dashboard:** наблюдение за сигналами одновременно с показаниями приборов.
- **Data Logger + Performance:** сопоставление сигналов датчиков с расчётными характеристиками.

# MCP-сервер

LibreTune может предоставлять свои инструменты анализа калибровок **внешним ИИ-агентам** через локальный сервер [Model Context Protocol](https://modelcontextprotocol.io). Агент, запущенный в Claude Code, Claude Desktop или другом MCP-клиенте, сможет читать открытую калибровку и анализировать её с помощью тех же детерминированных инструментов, которые использует встроенный [ИИ-ассистент](./ai-assistant.md).

> **Только чтение.** MCP-сервер не предоставляет инструментов для изменения калибровки, создания предложений или обращения к ЭБУ. Внешний агент может только просматривать данные; изменять их можете только вы.

По умолчанию сервер **выключен** и прослушивает только адрес `127.0.0.1` — подключиться к нему с другого компьютера невозможно.

## Включение сервера

1. Откройте **Tools → Settings**.
2. Прокрутите до раздела **AI Assistant (at your own risk) → MCP server (local)**.
3. Установите флажок **Expose tools over MCP**.

Сервер запускается сразу. В подписи флажка отображается адрес привязки, например `Running on 127.0.0.1:8765`. Чтобы остановить сервер, снимите флажок или закройте LibreTune. Настройка запоминается, поэтому оставленный включённым сервер запустится при следующем старте приложения.

В отличие от остальных параметров окна Settings, настройки MCP применяются сразу, а не после нажатия **OK**: каждое действие открывает или закрывает реальный сетевой сокет.

## Аутентификация

Каждый запрос должен содержать bearer-токен:

```
Authorization: Bearer <token>
```

Для каждой установки создаётся уникальный токен длиной 64 шестнадцатеричных символа. Он отображается в разделе настроек **Access token** (нажмите **Show**). Токен хранится в файле `mcp-token` в каталоге данных приложения LibreTune. В macOS и Linux прочитать его может только ваша учётная запись. Токен никогда не записывается в `settings.json` или журналы.

Нажмите **Regenerate**, чтобы создать новый токен. Старый перестаёт работать немедленно. Если сервер запущен, он перезапускается на том же порту с новым токеном. После этого обновите конфигурацию клиента.

## Доступные инструменты

Все восемь инструментов доступны только для чтения. Это те же инструменты, которые использует встроенный ассистент, поэтому внешний агент получает те же данные, что и ассистент.

| Инструмент | Что возвращает |
|---|---|
| `list_tables` | Все редактируемые таблицы, их назначение (VE / Ignition / AFR target / …) и размеры. Сначала вызовите этот инструмент, чтобы узнать имена таблиц. |
| `read_table` | Текущие значения, узлы осей и единицы измерения одной таблицы. |
| `read_constant` | Значение одной константы, минимум/максимум, единицы измерения и варианты. |
| `list_features` | Константы-переключатели функций (bits) и доступные варианты. |
| `summarize_tune_context` | Ошибку AFR для каждой ячейки, охват данными, подозрительные и ещё не исследованные ячейки таблицы VE. |
| `tune_health_check` | Общую оценку состояния и охват данными по областям таблицы. |
| `get_realtime_snapshot` | Текущие значения датчиков (RPM, MAP, TPS, CLT, AFR и т. д.). Требуется активное подключение. |
| `query_datalog` | Статистику по каналам или последние строки текущего сеанса либо сохранённого журнала. |

Значения возвращаются в **исходных единицах ЭБУ**, а не в единицах, выбранных для отображения. У внешней модели нет контекста настроек отображения, а незаметное преобразование чисел могло бы привести к ошибкам при вычислениях.

Инструменты `propose_*` встроенного ассистента намеренно **не предоставляются** через MCP. Предложение имеет смысл только внутри очереди проверки LibreTune; если внешний агент попытается вызвать такое имя через MCP, запрос будет отклонён, а не проигнорирован.

## Подключение Claude Code

```bash
claude mcp add --transport http libretune http://127.0.0.1:8765/mcp \
  --header "Authorization: Bearer TOKEN"
```

Замените `TOKEN` значением из поля **Access token**. В разделе настроек также отображается эта команда с текущим номером порта. Нажмите на неё, чтобы выделить и скопировать.

## Подключение Claude Desktop

Интерфейс конфигурации Claude Desktop не умеет отправлять статические заголовки. Поэтому используйте мост `mcp-remote` (требуется Node.js):

```json
{
  "mcpServers": {
    "libretune": {
      "command": "npx",
      "args": ["mcp-remote", "http://127.0.0.1:8765/mcp", "--allow-http",
               "--transport", "http-only",
               "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer TOKEN" }
    }
  }
}
```

Пробел после `Authorization:` должен находиться внутри переменной окружения, как показано выше. Это обходной путь для особенности экранирования аргументов в Claude Desktop.

## Изменение порта

Установите значение **Port** (минимум 1024) и нажмите **Apply port**. Если сервер был запущен, он перезапустится на новом порту. Если порт уже занят, ошибка появится под элементами управления, а сервер останется остановленным. Выберите другой порт или освободите текущий (`lsof -i :8765` в macOS/Linux, `netstat -ano` в Windows).

## Безопасность

- **Только loopback.** Сервер привязывается к `127.0.0.1`, а не к `0.0.0.0`.
- **Сравнение токена за постоянное время.** Bearer-токен сравнивается без досрочного выхода, поэтому его байты нельзя восстановить по времени ответа.
- **Проверка Host и Origin.** Оба заголовка ограничены локальными адресами, что блокирует DNS-rebinding-атаки со страниц браузера.
- **Нет операций записи.** Инструментов `apply`, `burn` и `propose` нет.

На неудачный запрос сервер отвечает пустым статусом `401` без тела ответа и никогда не возвращает отправленный клиентом токен.

## Пример сеанса

1. Откройте проект в LibreTune и включите MCP-сервер.
2. Подключите Claude Code командой, приведённой выше.
3. Задайте вопрос, для ответа на который нужна калибровка, например:
   - *«Прочитай мою таблицу VE и укажи области с недостаточным охватом данными».*
   - *«Оцени состояние таблицы veTable1».*
   - *«Какие значения датчиков сейчас отображаются?»*
4. Агент вызовет `list_tables`, `read_table`, `summarize_tune_context` и другие инструменты и ответит на основе реальных данных.
5. Чтобы применить рекомендацию, внесите изменение самостоятельно — в редакторе таблиц или через встроенный [ИИ-ассистент](./ai-assistant.md), у которого есть инструменты предложений и очередь проверки.

## Устранение неполадок

| Проблема | Вероятная причина / решение |
|---|---|
| Клиент сообщает `401 Unauthorized` | После настройки клиента токен был обновлён. Скопируйте актуальный токен из Settings. |
| Сервер не запускается | Порт занят. Выберите другой порт или освободите текущий. |
| `get_realtime_snapshot` возвращает ошибку | Нет активного подключения к ЭБУ. Сначала подключитесь. |
| `read_table` сообщает, что описание INI не загружено | Откройте проект, чтобы загрузить описание и калибровку. |
| `query_datalog` не находит записей | Запустите регистрацию данных или укажите сохранённый журнал из папки datalogs проекта. |
| В клиенте пустой список инструментов | Клиент подключился, но сеанс прервался. Подключитесь повторно и проверьте, что LibreTune запущена и переключатель сервера включён. |

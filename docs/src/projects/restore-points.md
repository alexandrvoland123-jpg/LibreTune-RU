# Точки восстановления

Быстрые резервные копии для защиты калибровки.

## Что такое точки восстановления?

Точки восстановления — это снимки текущей калибровки с отметкой времени:
- Создаются вручную или автоматически.
- Быстро создаются и восстанавливаются.
- Проще полноценного контроля версий.

## Создание точек восстановления

### Вручную
1. Выберите **Файл → Создать точку восстановления**.
2. Точка будет создана немедленно.
3. Появится подтверждение.

### Автоматически
Точки восстановления создаются автоматически:
- перед загрузкой другой калибровки;
- перед выполнением важных операций;
- через заданный интервал времени (настраивается).

## Просмотр точек восстановления

1. Выберите **Файл → Точки восстановления…**.
2. В списке отображаются все точки восстановления.
3. Список отсортирован по дате: сначала новые.

### Информация о точке
- **Имя файла**: имя с отметкой времени.
- **Дата**: время создания.
- **Размер**: размер файла.

## Восстановление точки

1. Откройте окно «Точки восстановления».
2. Выберите нужную точку.
3. Нажмите **Загрузить**.
4. Подтвердите действие, если есть несохранённые изменения.
5. Калибровка будет восстановлена.

**Предупреждение:** текущая калибровка будет заменена. При необходимости сначала создайте новую точку восстановления.

## Удаление точек восстановления

1. Выберите точку восстановления.
2. Нажмите **Удалить**.
3. Подтвердите удаление.

### Массовое удаление
- Щёлкните правой кнопкой мыши и выберите **Удалить старше…**.
- Укажите период.
- Старые точки будут удалены.

## Автоматическая очистка

В настройках можно задать максимальное количество точек восстановления:
- По умолчанию: 20 точек.
- При достижении лимита удаляются самые старые.
- Последние резервные копии сохраняются.

## Точки восстановления и контроль версий

| Возможность | Точки восстановления | Контроль версий |
|---|---|---|
| Настройка | Не требуется | Инициализация репозитория |
| История | Линейный список | Полное дерево коммитов |
| Ветвление | Нет | Да |
| Сообщения | Только отметки времени | Пользовательские сообщения |
| Сравнение | Нет | Да (diff) |
| Сложность | Просто | Больше возможностей |

### Что выбрать

**Точки восстановления:** быстрые резервные копии и простые задачи; знание Git не требуется.

**Контроль версий:** подробная история, эксперименты, совместная работа и профессиональный рабочий процесс.

## Расположение файлов

Точки восстановления хранятся в каталоге:
```
[Project Folder]/restore-points/
├── tune_2026-01-11_14-30-00.msq
├── tune_2026-01-11_12-15-00.msq
└── ...
```

Эти файлы можно вручную копировать для внешнего резервного хранения.

# Примечания к изменениям

Примечания позволяют прикрепить короткий комментарий к коммиту калибровки. Это помогает понять, *почему* было внесено изменение, когда вы просматриваете историю.

## Добавление примечания

1. Откройте **Инструменты → История калибровки**.
2. Нажмите **Коммит**.
3. Введите сообщение коммита.
4. При запросе добавьте необязательное примечание.

Примечания сохраняются вместе с коммитом и отображаются непосредственно на временной шкале истории.

## Рекомендации по использованию

- Кратко описывайте внесённые изменения (например: «Обеднил смесь при средней нагрузке для более плавного движения на постоянной скорости»).
- Указывайте условия испытаний: температуру окружающего воздуха, тип топлива, давление наддува.
- Записывайте причину, по которой потребовался откат изменений.

# Управление калибровками

Сохранение, загрузка и упорядочивание файлов калибровок.

## Формат файла калибровки

LibreTune использует стандартный формат MSQ:
- хранение калибровки на основе XML;
- совместимость с TunerStudio;
- возможность чтения в любом текстовом редакторе.

## Сохранение калибровок

### Быстрое сохранение
- Нажмите `Ctrl+S` или кнопку **Сохранить**.
- Текущий файл калибровки будет перезаписан.
- Если функция включена, будет создана точка восстановления.

### Сохранить как
- Выберите **Файл → Сохранить калибровку как…**.
- Укажите новое имя файла.
- Исходный файл останется без изменений.

### Автосохранение
Настройте параметры в разделе «Настройки»:
- **Интервал**: периодичность автосохранения.
- **Расположение**: каталог для резервных копий.
- **Количество**: сколько копий сохранять.

## Загрузка калибровок

### Из проекта
1. Выберите **Файл → Загрузить калибровку**.
2. Укажите файл MSQ.
3. Значения будут загружены в текущий проект.

### Из другого проекта
1. Перейдите в каталог любого проекта.
2. Выберите файл калибровки.
3. Значения будут объединены с текущим INI.

## Запись в ЭБУ

Запись калибровки в постоянную flash-память ЭБУ:

1. Подключитесь к ЭБУ.
2. Внесите необходимые изменения.
3. Выберите **Файл → Записать в ЭБУ** или нажмите `Ctrl+B`.
4. Подтвердите запись.
5. Дождитесь завершения операции.

### Когда записывать

**Выполняйте запись, если:**
- изменения проверены и подтверждены;
- нужно сохранить их после выключения питания;
- автомобиль готовится к обычной дорожной эксплуатации.

**Не выполняйте запись, если:**
- изменения ещё проверяются;
- вы экспериментируете со значениями;
- результаты ещё не подтверждены.

### Защита от случайной записи

Перед записью LibreTune:
- показывает количество изменённых значений;
- запрашивает подтверждение;
- предупреждает, что отменить запись нельзя (используйте точки восстановления!).

## Сравнение калибровок

Для сравнения двух файлов:
1. Выберите **Инструменты → Сравнить калибровки**.
2. Выберите первую калибровку или используйте текущую.
3. Выберите вторую калибровку.
4. Различия отобразятся в таблице.

### Отображение различий
- **Зелёный**: значения есть только во второй калибровке.
- **Красный**: значения есть только в первой калибровке.
- **Жёлтый**: значения различаются.

## Сброс к значениям по умолчанию

Чтобы вернуть всем значениям значения из INI:
1. Выберите **Инструменты → Сбросить значения по умолчанию**.
2. Подтвердите сброс.
3. Все константы будут сброшены к значениям по умолчанию.

**Предупреждение:** отменить это действие нельзя. Сначала создайте точку восстановления.

## Экспорт и импорт

### Экспорт в CSV
1. Выберите **Файл → Экспортировать калибровку в CSV**.
2. Все константы будут экспортированы вместе с метаданными.
3. Это удобно для анализа и резервного копирования.

### Импорт из CSV
1. Выберите **Файл → Импортировать калибровку из CSV**.
2. Значения будут проверены на соответствие INI.
3. Проверенные значения будут применены к текущей калибровке.

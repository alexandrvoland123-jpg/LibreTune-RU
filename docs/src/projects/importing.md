# Импорт проектов

Импорт проектов из TunerStudio и других источников.

## Импорт проекта TunerStudio

### Какие данные импортируются
- **Файл описания INI**
- **Текущая калибровка** (`CurrentTune.msq`)
- **Точки восстановления** (если имеются)
- **Переменные ПК** (`pcVariableValues.msq`)
- **Настройки подключения** (порт, скорость передачи)

### Процесс импорта

1. Выберите **Файл → Импорт проекта TS...**.
2. Укажите папку проекта TunerStudio.
3. В окне предварительного просмотра проверьте список импортируемых данных.
4. Нажмите **Импортировать**.
5. Проект будет создан в LibreTune.

### Где находятся папки проектов

Обычно проекты TunerStudio хранятся здесь:
- **Windows**: `Documents\TunerStudioProjects\`
- **macOS**: `Documents/TunerStudioProjects/`
- **Linux**: `~/TunerStudioProjects/`

## После импорта

### Проверьте соответствие INI

LibreTune проверяет, соответствует ли файл INI проекту:
- ✅ **Совпадает**: проект готов к работе.
- ⚠️ **Не совпадает**: возможно, потребуется другой файл INI.

### Проверьте подключение

Настройки по умолчанию импортируются автоматически, но их следует проверить:
1. Откройте настройки подключения.
2. Убедитесь, что выбраны правильные порт и скорость передачи.
3. Проверьте соединение.

## Импорт только калибровки

Чтобы импортировать файл MSQ в существующий проект:
1. Выберите **Файл → Загрузить калибровку**.
2. Укажите любой файл MSQ.
3. Значения будут загружены, если файл совместим с используемым INI.

## Импорт файла INI

Чтобы добавить INI в локальный репозиторий:
1. Откройте **Настройки** (`Ctrl+Comma`) → вкладку **Определения ЭБУ**.
2. Нажмите **Импортировать определение ЭБУ**.
3. Выберите файл INI.
4. Файл будет скопирован в репозиторий и станет доступен при создании проектов.

Файл INI также можно импортировать непосредственно во время [открытия файла калибровки](../getting-started/first-project.md#открытие-файла-калибровки). Если подходящий INI не найден, в диалоговом окне появится кнопка **Импортировать определение ЭБУ...**.

### Управление библиотекой INI

Чтобы просмотреть или удалить импортированные файлы INI, откройте **Настройки → Определения ЭБУ**. Подробности приведены в разделе [Настройки — Определения ЭБУ](../getting-started/settings.md#описания-эбу).

## Импорт панелей приборов

Чтобы импортировать макет панели TunerStudio:
1. Выберите **Файл → Импорт панели приборов...**.
2. Укажите файл `.dash`.
3. Панель будет преобразована в формат LibreTune.
4. Она появится в списке выбора панелей.

## Устранение проблем при импорте

### «Файл INI не найден»

Проект ссылается на INI, которого нет в папке:
1. Найдите правильный файл INI.
2. Поместите его в папку проекта.
3. Либо выберите другой INI при импорте.

### «Несовместимый формат калибровки»

Файл MSQ не соответствует структуре INI:
1. Найдите INI для используемой версии прошивки.
2. Либо используйте MSQ, сохранённый соответствующей версией прошивки.
3. Сигнатуры должны совпадать.

### «Нет точек восстановления»

TunerStudio не создала точки восстановления:
1. Для новых проектов это нормально.
2. В дальнейшем создавайте точки восстановления в LibreTune.

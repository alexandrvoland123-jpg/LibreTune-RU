# Контроль версий

Отслеживание истории калибровок с помощью системы версионирования на базе Git.

## Обзор

LibreTune может использовать Git для отслеживания изменений калибровки:
- полная история всех изменений;
- восстановление любой предыдущей версии;
- создание веток для экспериментов;
- сравнение версий.

## Включение контроля версий

### Новые проекты
При создании проекта установите флажок **Включить контроль версий**.

### Существующие проекты
1. Откройте **Файл → История калибровки**.
2. Нажмите **Инициализировать репозиторий**.
3. Отслеживание Git будет запущено.

## Принцип работы

После включения LibreTune:
1. Создаёт Git-репозиторий в каталоге проекта.
2. Фиксирует изменения при сохранении (в соответствии с настройками).
3. Отслеживает все изменения файлов калибровки.

## Настройки автоматических коммитов

Настраиваются в разделе **Настройки → Контроль версий**:

| Параметр | Поведение |
|---|---|
| **Никогда** | Только ручные коммиты |
| **Всегда** | Коммит при каждом сохранении |
| **Спрашивать** | Запрашивать подтверждение каждый раз |

### Формат сообщения коммита

Можно настроить шаблон автоматического сообщения:
- `{date}` — текущая дата;
- `{time}` — текущее время;
- `{table}` — имя последней редактировавшейся таблицы.

Пример: `Tune saved on {date} at {time}`

## Просмотр истории

1. Выберите **Файл → История калибровки** или нажмите значок истории.
2. На временной шкале отображаются все коммиты.
3. Нажмите на коммит, чтобы увидеть подробности.

### Сведения о коммите
- дата и время;
- сообщение коммита;
- изменённые файлы.

## Восстановление предыдущих версий

1. Откройте историю калибровки.
2. Найдите нужный коммит.
3. Нажмите **Переключиться на эту версию (Checkout)**.
4. Подтвердите восстановление.
5. Калибровка будет возвращена к выбранной версии.

**Примечание:** все незакоммиченные изменения будут потеряны. Сначала сохраните их!

## Сравнение версий

1. Выберите коммит в истории.
2. Нажмите **Просмотреть различия (View Diff)**.
3. Просмотрите изменения между версиями.

### Окно различий
- показывает изменения по каждому файлу;
- выделяет изменённые значения;
- помогает определить, что именно изменилось.

## Ветвление

Создавайте отдельные ветки для экспериментальных калибровок.

### Создание ветки
1. Откройте историю калибровки.
2. Нажмите **Новая ветка**.
3. Введите имя ветки.
4. Ветка будет создана от текущего состояния.

### Переключение ветки
1. Откройте раскрывающийся список веток.
2. Выберите нужную ветку.
3. Калибровка переключится на состояние этой ветки.

### Примеры использования
- **Main**: стабильная рабочая калибровка.
- **E85 experiment**: испытания топлива E85.
- **Track day**: настройки угла опережения зажигания для трек-дня.

## Ручные коммиты

Чтобы создать коммит с собственным сообщением:
1. Откройте историю калибровки.
2. Нажмите **Коммит**.
3. Введите понятное описание.
4. Коммит будет создан.

### Примеры хороших сообщений
- «Увеличил VE на 5% по всей таблице».
- «Устранил переобогащение при 3000 об/мин / 60 кПа».
- «Резервная копия перед трек-днём».

## Советы

### Создавайте коммиты регулярно
- перед крупными изменениями;
- после успешных испытаний;
- когда получено заведомо рабочее состояние.

### Используйте ветки
- сохраняйте основную ветку стабильной;
- проводите эксперименты в отдельных ветках;
- объединяйте изменения после проверки.

### Пишите понятные сообщения
- описывайте, что и почему изменили;
- указывайте связанные задачи или цели.

# История изменений

Все значимые изменения LibreTune документируются в этом файле.

## [Не выпущено]

### Добавлено
- **3D-вид для каждой таблицы** — переключение 3D-вида теперь доступно во всех редакторах таблиц, включая таблицы, встроенные в диалоговые окна. Нажмите кнопку 3D, чтобы переключаться между двумерной сеткой и интерактивной трёхмерной поверхностью.
- **Редактирование кривых перетаскиванием** — редактируйте одномерные кривые: щёлкните в любой точке графика, чтобы выбрать ближайшую точку, и перетащите её вверх или вниз. Перетаскивание продолжается, даже если курсор выходит за пределы графика; изменение применяется после отпускания кнопки мыши.
- **Генератор базовой карты** — создание безопасных начальных калибровок на основе характеристик двигателя (число цилиндров, рабочий объём, размер форсунок, тип топлива, тип наддува и т. д.). Генерируются таблицы VE, зажигания, AFR и кривые обогащения. Доступен из стартового окна и меню Tools.
- **Рабочий процесс, ориентированный на файлы** — проекты теперь создаются автоматически при открытии файла калибровки. В стартовом окне доступны три основных действия: Open Tune File, Connect to ECU и Import TS Project.
- **Диалог Open Tune File** — выбор файлов `.msq`/`.xml` с автоматическим подбором INI по сигнатуре, панелью предварительного просмотра и созданием проекта одним нажатием.
- **Управление описаниями ЭБУ** — новая вкладка Settings для просмотра, импорта и удаления INI-файлов.
- **Удаление проектов** — удаление проектов непосредственно из списка недавних проектов стартового окна (для защиты требуется подтверждение нажатием).
- **Консоль ЭБУ** — текстовый интерфейс команд для ЭБУ rusEFI, FOME и epicEFI. Доступна через Tools → ECU Console при подключении к поддерживаемому ЭБУ. Есть навигация по истории команд, цветовое выделение вывода и оптимизация быстрого обмена FOME.
- **Отдельные окна** — любую вкладку можно вынести в отдельное окно для работы с несколькими мониторами. Двусторонняя синхронизация поддерживает актуальность данных реального времени, изменений таблиц и состояния подключения во всех окнах.
- **Перенос калибровок** — автоматическое отслеживание версии INI и формирование отчёта при открытии калибровок, сохранённых с другой версией прошивки. Отчёт показывает категории изменений с указанием серьёзности: изменение типов и масштабирования, добавление или удаление констант.
- **Создание приборов перетаскиванием** — перетаскивайте каналы из боковой панели на приборную панель в режиме Designer Mode. Метаданные INI (единицы, минимум/максимум, предупреждения) заполняются автоматически.
- **Интеллектуальная запись** — автоматическая запись журнала данных при наступлении заданных условий (порог RPM, активация TPS и т. д.).
- **Статистика данных** — статистический анализ записанных данных с расчётом минимума, максимума, среднего значения и стандартного отклонения для каждого канала.
- **Правила оповещений** — настраиваемые условия, запускающие уведомления или действия при выходе значений каналов за пороговые пределы.
- **Сценарии Lua** — встроенный механизм Lua для пользовательских вычислений, автоматизированных последовательностей тестирования и расширенной обработки данных.
- **Математические каналы** — механизм выражений для создания вычисляемых каналов на основе данных ЭБУ (например, ошибка AFR, эффективность VE, разница давления наддува).
- **Калькулятор производительности** — оценка мощности и крутящего момента на основе физических моделей, характеристик автомобиля и данных разгона.
- **Диагностические регистраторы** — Tooth Logger для анализа рисунка триггера коленвала/распредвала и Composite Logger для визуализации осциллограмм нескольких каналов с определением состояния синхронизации.
- **Настройка оборудования** — визуальный редактор портов/контактов для назначения цифровых выходов, форсунок и катушек зажигания с обнаружением конфликтов.
- **Сценарии действий** — запись, повторное выполнение и обмен последовательностями действий настройки в виде JSON-сценариев. Поддерживаются условное выполнение и базовые шаблоны.
- **Аннотации изменений** — добавление примечаний к отдельным изменениям калибровки с объяснением назначения каждой правки.
- **Система плагинов WASM** — безопасная изолированная архитектура плагинов на основе WebAssembly. Плагины объявляют разрешения и работают без внешних зависимостей.
- **Проверка панелей приборов** — автоматическая проверка конфигураций панелей на соответствие определениям каналов INI.
- **ИИ-ассистент** — помощник на базе выбранной пользователем языковой модели для настройки и конфигурирования ЭБУ. Поддерживаются провайдеры OpenAI, Anthropic и Google, а также локальные конечные точки, совместимые с OpenAI, например Ollama. Ассистент только *предлагает* изменения: каждое предложение проверяется по INI, ограничивается допустимыми пределами и помещается в очередь проверки для явного подтверждения пользователем. Автоматическая запись в ЭБУ не выполняется. Ассистент расположен в закреплённой боковой панели, размер которой можно менять, а саму панель можно вынести в отдельное окно. Функция требует отдельного включения с предупреждением «на свой риск».
- **ИИ-ассистент (расширение)** — теперь ассистент применяет одобренные предложения к рабочей калибровке (сначала создаётся точка восстановления, запись в ЭБУ по-прежнему не выполняется автоматически); соблюдает уровни возможностей (read / tune / config, накапливаемые) как для доступных инструментов, так и для входящих вызовов; читает снимки текущих показаний датчиков и журналы данных (сводная статистика или последние строки); отмечает конфликты контактов и большие пакетные изменения; показывает текущий ход чтения «reading X…», счётчик токенов для каждого чата и кнопку **Ask AI** в каждом редакторе таблиц; хранит API-ключ в системном хранилище ключей ОС; предлагает готовые настройки провайдеров, включая локальные Ollama / LM Studio. Результаты чтения учитывают выбранные единицы отображения.
- Контроль версий калибровок на основе Git: история коммитов, ветки и настройки автоматических коммитов.
- Полноценная система документации (документация API и руководство пользователя).
- Панель TuneHistoryPanel для просмотра истории калибровок и управления ею.
- Настройки контроля версий в диалоге Settings.
- Автоматическая синхронизация и повторное подключение после команд контроллера (параметр Settings).
- Динамический заголовок окна с названием текущего проекта.
- Название проекта в заголовке боковой панели.
- Отображение номера сборки в окне About (формат `YYYY.MM.DD+g<sha>`).
- Быстрый обмен FOME с интеллектуальным переходом на резервный режим для оптимизации связи с консолью.
- Защита вкладки Dashboard: её нельзя случайно закрыть; восстановление доступно через View → Dashboard.
- Настраиваемые каналы строки состояния (Settings → Status Bar Channels, максимум 8).
- Диалог несовпадения сигнатуры INI с поиском локальных и сетевых INI (сетевой поиск теперь запускается автоматически при обнаружении несовпадения; загрузка по-прежнему требует явного нажатия).
- Поиск INI в официальных онлайн-репозиториях: Speeduino (GitHub и Releases), rusEFI и epicEFI (официальные серверы пакетов), FOME (INI, формируемые для каждой платы).
- Импорт/экспорт отдельных файлов `.table` (совместимая с TunerStudio функция «Save/Load Table to File» на панели инструментов таблицы).
- Тест задержки AFR (Tools → AFR Delay Test…) — автоматическое измерение задержки прохождения выхлопных газов: программа изменяет подачу топлива и определяет задержку, которую нужно указать как lambda delay в AutoTune.
- Более надёжная синхронизация ЭБУ с обработкой частичных сбоев и индикатором в строке состояния.
- Импорт и экспорт данных калибровки в CSV.
- Сброс калибровки к значениям по умолчанию.
- Настройка Runtime Packet Mode (Auto / Force Burst / Force OCH / Disabled).
- Журналирование backend теперь управляется через `RUST_LOG` с использованием `tracing` (по умолчанию `info`); отладочный вывод протокола ЭБУ можно снова включить через `RUST_LOG=libretune_core::protocol=debug`.

### Изменено
- Шаблонный процесс «New Project» заменён рабочим процессом «Open Tune File», ориентированным на открытие файлов.
- Стартовый экран переработан: теперь на нём три основных действия и список недавних проектов.
- В меню File пункт «New Project» переименован в «Open Tune File» (Ctrl+N); пункт «Open Project» удалён.
- Импорт INI перенесён из меню File во вкладку Settings → ECU Definitions.
- Улучшен AutoTune: добавлена фильтрация переходных процессов, компенсация задержки lambda и контроль пределов допустимого влияния.
- Улучшено отображение приборов: металлические ободки, 3D-эффекты и градиентная заливка для всех 13 типов приборов.
- В редакторе таблиц используется плоская CSS-сетка для точного выравнивания осей по пикселям.
- Поток данных реального времени переведён с опроса на событийную архитектуру (интервалы 50 мс).
- Добавлена диагностика блокировок подключения с отслеживанием владельца блокировки.

### Удалено
- Встроенные шаблоны проектов (Speeduino, rusEFI, epicEFI) — заменены генератором базовой карты.
- Диалоги «New Project» и «Open Project» — заменены функциями Open Tune File и Welcome View.
- Интерфейс системы плагинов Java/JVM (устарел; см. DEPRECATION_NOTICE.md).

### Исправлено
- AutoTune больше не теряет от трети до половины выборок на реальном оборудовании: окно сопоставления отложенных выборок теперь соответствует частоте потока; также исключаются показания при отсечке топлива на сбросе газа и предельные значения широкополосного датчика.
- Тест задержки AFR теперь сообщает медианную задержку прохождения (половина полного отклонения), а не нестабильное значение по переднему фронту; запрещает одновременный повторный запуск и отображает окно стабилизации/восстановления.
- Проверка конфликтов контактов игнорирует контакты, занятые только отключёнными функциями, считает «Board Default» неназначенным значением и больше не блокирует загрузку калибровки.
- Точность отображения диалогов: поля с условием доступности отключаются, а не скрываются; подписи кнопок команд и панелей индикаторов, а также динамические единицы вычисляются вместо показа исходных выражений; панели индикаторов без явного числа столбцов отображаются корректно.
- Боковая панель подсвечивает текущий открытый элемент дерева проекта.
- Редактор таблиц: сочетание клавиш Interpolate больше не переводит фокус в поле поиска; подписи оси Y видны в таблицах с количеством строк более 12.
- Перетаскивание элементов панели приборов работает внутри Tauri webview.
- Исправлен бесконечный цикл повторного рендеринга HotkeyEditor в диалоге Settings.
- Операции с таблицами (scale, smooth, interpolate, set equal, rebin) теперь корректно связаны с backend.
- Исправлен поиск таблиц AutoTune для INI rusEFI/epicEFI (разрешение `veTable1Map` → `veTable1Tbl`).
- Устранена конкуренция за блокировку потока данных реального времени из-за `get_all_constant_values`, блокировавшей последовательное соединение.
- Вкладку Dashboard больше нельзя случайно закрыть нажатием средней кнопки мыши или выносом в отдельное окно.
- Исправлено выравнивание подписей осей таблиц во встроенном редакторе (используется плоская сетка).
- Исправлена обработка ключевого слова `lastOffset` при разборе констант INI.
- `std_separator` больше не отображается как пункт меню вместо разделителя.
- PcVariables теперь доступны диалогам (они разбираются как полноценные Constants).
- Исправлена ошибка индексации массива весов при сглаживании таблицы.

## [0.1.0] — 2026-01-01

### Добавлено
- Первый выпуск.
- Подключение к ЭБУ через последовательный порт.
- Разбор файлов описания INI.
- Редактирование таблиц (2D/3D).
- Панель приборов реального времени с настраиваемыми индикаторами.
- AutoTune с коррекцией VE на основе AFR.
- Регистрация и воспроизведение данных.
- Импорт проектов TunerStudio.
- Система точек восстановления.
- Поиск INI в онлайн-репозиториях.
- Отдельные окна для работы с несколькими мониторами.
- Преобразование единиц измерения (температура, давление, AFR/Lambda).

- rusEFI
- epicEFI
